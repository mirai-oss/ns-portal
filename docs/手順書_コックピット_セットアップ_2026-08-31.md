## ④ 自動heartbeat（H-5・PC1台につき1回）

2つの仕組みを1コマンドで入れる（何度実行しても安全・既存設定は保持）:
- **Claude Codeフック**: 新しく起動するセッションが自動で報告（作業中=実装中・応答完了=待機）
- **常駐ウォッチャー（LaunchAgent）**: 30秒ごとに全リポジトリをスキャンし、直近3分に変更のあったリポジトリぶんhbを送信。フック導入前から動いている古いセッションやVS Code等の作業も拾う。PC再起動後も自動で動く

各Macのターミナルで実行:

```bash
cd ~/ns-portal && git pull
```

続けて下のブロックを丸ごと実行（フック＋ウォッチャーを一度に設定）:

```bash
python3 - <<'EOF'
import json, os, subprocess
home = os.path.expanduser("~")
# ① Claude Codeフック（次に起動するセッションから自動報告）
p = os.path.join(home, ".claude", "settings.json")
try: s = json.load(open(p))
except Exception: s = {}
CMD = '[ -x "$HOME/ns-portal/tools/ai-cockpit" ] && "$HOME/ns-portal/tools/ai-cockpit" %s >/dev/null 2>&1 || true'
h = s.setdefault("hooks", {})
def add(event, matcher, action):
    lst = h.setdefault(event, [])
    if any("ai-cockpit" in hk.get("command","") for e in lst for hk in e.get("hooks",[])):
        print(event + ": 設定済み"); return
    e = {"hooks":[{"type":"command","command":CMD % action,"timeout":15,"async":True}]}
    if matcher: e["matcher"] = matcher
    lst.append(e); print(event + ": 追加")
add("SessionStart", None, "hb")
add("PostToolUse", "Edit|Write|Bash|NotebookEdit", "hb")
add("Stop", None, "idle")
os.makedirs(os.path.dirname(p), exist_ok=True)
json.dump(s, open(p, "w"), ensure_ascii=False, indent=2)
print("フックOK:", p)
# ② 常駐ウォッチャー（LaunchAgent・再起動後も自動で動く）
plist = os.path.join(home, "Library", "LaunchAgents", "com.nstyle.ai-cockpit-watch.plist")
os.makedirs(os.path.dirname(plist), exist_ok=True)
open(plist, "w").write(f'''<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
<key>Label</key><string>com.nstyle.ai-cockpit-watch</string>
<key>ProgramArguments</key><array><string>/usr/bin/python3</string><string>{home}/ns-portal/tools/ai-cockpit</string><string>watch</string></array>
<key>RunAtLoad</key><true/>
<key>KeepAlive</key><true/>
<key>StandardOutPath</key><string>/tmp/ai-cockpit-watch.log</string>
<key>StandardErrorPath</key><string>/tmp/ai-cockpit-watch.log</string>
</dict></plist>''')
subprocess.run(["launchctl", "unload", plist], capture_output=True)
r = subprocess.run(["launchctl", "load", plist], capture_output=True, text=True)
print("ウォッチャーOK（30秒ごとに全リポジトリ監視）" if r.returncode == 0 else "ウォッチャー登録エラー: " + r.stderr)
EOF
```

解除したいとき: `launchctl unload ~/Library/LaunchAgents/com.nstyle.ai-cockpit-watch.plist`（ログ: /tmp/ai-cockpit-watch.log）

- 仕組み: セッション開始・ファイル編集/コマンド実行のたび→`ai-cockpit hb`（20秒間引き）／応答完了→`idle`。担当名を名乗らないセッションはリポジトリ名で表示される
- 事前条件: そのPCに `~/ns-portal`（git pull済み）と `~/.ns-cockpit/config`（②）があること

## トークンを変えたくなったら

新しい値で①-3のSQLを再実行 → 各PCの `~/.ns-cockpit/config` のTOKEN行を書き換え。
