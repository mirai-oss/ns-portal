## 1. ①請求書（メール）→広告費入力への自動反映

**要望**: MFに入力した請求書のうち食べログ・ぐるなび等の広告費を、広告費入力（広告費用対効果_管理シートの💾広告費DB）へ自動反映したい。請求書処理時に「何の広告か」を推定表示→選択すれば店舗×金額が自動連携。店舗別金額が請求書に無い場合はMF仕訳の部門（店舗）を参考にする。

### 実装案
1. **判定**: 請求書のOCR結果・送信元（例: tabelog.com／gnavi）・過去の処理履歴から「広告費らしさ」と媒体（食べログ/ぐるなび/ホットペッパー等）を推定し、`invoices.html`の処理画面に**「📢 広告費として反映」パネル**を表示（媒体・対象年月・店舗×金額の割り振り案を提示→人が確認・修正して確定。AI=下書き・人=承認の原則どおり）
2. **店舗×金額の割り振り**: 優先順= a)請求書明細に店舗別金額があればそれ b)無ければ同じ請求書で作ったMF仕訳の部門別金額 c)どちらも無ければ前月の同媒体の割り振り比率を提案
3. **書き込み先**: 広告費用対効果_管理シートの`💾広告費DB`（年月×店舗×媒体×金額）。書き込み経路は**経営ダッシュボードGASに書き込み用actionを追加**（GAS変更=担当A縄張り）し、invoices側のEdge Functionからそれを呼ぶ（invoicesから直接シートを触らない）。媒体名は既存の`tpl_media_alias`正規化を通す
4. **重複防止**: `invoices`に`ad_cost_synced_at`等の列を追加し、同じ請求書からの二重反映を防ぐ（MF仕訳の`mf_journal_id`と同型）
5. **担当分担**: invoices側UI・判定=担当C／GAS書き込みaction=担当A（Cから依頼）

## 2. ②精算書に勘定科目・補助科目を追加→店舗PLへ自動連携

**要望**: 精算書に入力している費用（電気料金・通信費等）は実際のPLに反映されるべきなので、精算書側に勘定科目・補助科目を付けて店舗PLへ自動連携したい。固定ロイヤリティ等はPL対象外なので「対象外」も選べるように。支払い（運営委託費）は今まで通りの自動連携を維持。

### 実装案
1. **精算システム（SeisanDashboard.gs）の明細入力に「勘定科目」「補助科目」列を追加**。科目リストはPL管理システムの科目マスタ（勘定科目・補助科目=A-1で整備済みの補助科目機構）と同じものを使う＋**「対象外」**選択肢（固定ロイヤリティ等・PLに送らない）
2. **既定値の自動提案**: 項目名からの推定（「電気」→水道光熱費 等）＋前月の同項目の科目を引き継ぎ（毎月選び直さなくてよい）
3. **PLへの連携**: 既存の`syncSeisanFeeToPl`（運営委託費の自動計上・毎朝）と同じパターンで、科目付きの明細を**店舗×年月×勘定科目×補助科目**でDB_PL（＋PL管理システム・stg_plミラー）へ`自動｜精算書`として計上する新関数を追加。**運営委託費の既存連携はそのまま**（二重計上にならないよう、新連携は「対象外」「運営委託費」以外の科目のみを送る）
4. **精算書UI刷新（A-7・別タスク）との関係**: UIの見た目刷新はモック（`docs/mockups/NStyle_統合ポータル_精算ダッシュボード_UI_v3_プレビューPDFメール対応.html`）準拠で先行。科目列の追加は本設計の確定後に「明細を入力」画面へ組み込む（同じ担当Aが順にやるのが安全）
5. **担当**: 精算GAS・PL連携とも**担当A**（GASデプロイ独占・PL連携の全実績あり）

## 3. ユーザーへの質問

- **Q1（広告費の反映先）**: 広告費の自動反映先は「広告費用対効果_管理シートの💾広告費DB」でよいですか？（今、月次の広告費を手入力している場所がここと違えば教えてください）
- **Q2（広告費の確定タイミング）**: 反映は「請求書を処理（仕訳登録）するとき」に一緒に確認→確定、でよいですか？
- **Q3（精算書の科目付け）**: 精算書の明細に科目を付けるのは、精算書を作っている本部の担当者が入力時に選ぶ形でよいですか？（前月コピー＋自動提案で手間は最小にします）
- **Q4（過去分）**: 精算書のPL連携は「これから作る精算書」からでよいですか？それとも過去の精算書もさかのぼって科目を付けてPLに反映したいですか？（さかのぼる場合は何ヶ月分か）

## 4. 確定仕様（2026-08-31 ユーザー回答で確定。実装はここに従う）

| Q | 回答 → 確定内容 |
|---|---|
| Q1 反映先 | **広告費用対効果_管理シートの💾広告費DBへ反映でOK**。ただし「今後Supabase/BigQueryへ正本を一括変更するならそちらにも登録しておいてほしい」→ **シートへの書き込みと同時にBigQueryにも同じ内容を記録する二重書き**で確定（新テーブル`stg_ad_cost`等。将来シートを廃止するときはBQ側が正本にそのまま昇格できる形にする） |
| Q2 タイミング | **仕訳登録した時点で確定・反映**（請求書処理フローの中で広告費パネルを確認→仕訳登録と同時に反映） |
| Q3 科目付け | **本部の入力担当が精算書入力時に選ぶ**（前月コピー＋項目名からの自動提案で手間最小化） |
| Q4 過去分 | **過去の分もさかのぼる** → 過去精算書の明細に科目を一括で付けられる「さかのぼり付与モード」を用意（前月コピーの連鎖＋自動提案で大半を埋め、人は確認・修正のみ）。**遡及の範囲（今期分か・それ以前も全部か）は着手時にデータ量を見て1問確認**（提案=まず今期2026年度分→問題なければ延長） |

## 5. 拡張: MF仕訳→PL連携の一般化（手数料など・2026-09-01ユーザー追加要望=項目5）

**要望**: カード手数料・PayPay手数料などをMFに会計入力（会計アップロードのところで入力）した時に、**店舗ごとにPLへ自動反映**したい。**精算書入力対象の店舗**（`stores.seisan_target`）については**精算書にも自動反映**。会計ダッシュボードの一覧にも状態が入るように。

**実装案（広告費連携=§1と同じ骨組みの科目汎用版）**:
1. 仕訳登録フロー（invoices・アップロード請求書・会計タブ）で、**PL連携対象の勘定科目**（支払手数料: カード・PayPay等。対象科目リストは実際のMF仕訳から候補を出してユーザー確認=手数料Q1）に該当する場合、「📊 PLへ反映」パネルを表示（店舗×金額の割り振り→確認→確定。部門があれば自動提案）
2. 確定でA-8のGAS書き込みactionを**科目汎用に拡張**して呼ぶ: DB_PLへ`自動｜◯◯（科目名）`行として店舗別に計上＋BQ併記。二重計上ガード（同じ仕訳からは1回だけ）
3. **精算対象店舗**の分は、精算書の費用明細にも同じ内容を自動追加（精算GAS=担当A。A-9の科目機構と同じ入れ物に入れる=科目付きで入るのでPL側と整合）
4. 会計ダッシュボード（C-7）の一覧に「PL反映済み／精算書反映済み」の状態列を追加
- **担当**: C（仕訳側パネル・状態列）＋A（A-8 actionの科目汎用化＋精算書自動追加）。**A-9・A-8と一体で実装するのが効率的**
- **手数料Q1（ユーザーへ）**: PLへ自動反映したい科目はカード手数料・PayPay手数料のほかに何がありますか？（こちらで直近のMF仕訳の科目一覧から候補を出して「これとこれ」と選んでもらう形でもOKです）
