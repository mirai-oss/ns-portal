# 手順書: LiveGateのスマレジ・タイムカードを管理システムとつなぐ（U1）／店舗「黒霧屋 新横浜」を登録する（U2）

作成: 担当D（2026-10-17）。対象: 中山さん。目的: 2026-11-01から黒霧屋 新横浜の運営がトーホー→LiveGateに変わるため、勤怠・給与をLiveGateのスマレジ契約から管理システムへ取り込めるようにします。
期限: **U1は10/24まで、U2は10/28まで**。
**スタッフの入社登録は、スマレジの画面では行いません**（管理システムの「LiveGateのスマレジに入社登録」ボタンで行います。この手順書には含みません）。

> ⚠️ スマレジの画面の名前や並びは、契約やバージョンで少し違うことがあります。**画面が違う・見つからないときは、その画面のスクリーンショットを送ってください**（こちらで正しい手順に直します）。パスワード・クライアントシークレットは**絶対に送らないでください**。送ってもらうのは「契約ID」だけです。

## U1: LiveGateのスマレジ・タイムカード契約を用意して、管理システムのアプリをつなぐ

### U1-1 LiveGateのスマレジ・タイムカードの契約を用意する
1. LiveGateで使うスマレジ・タイムカードの契約（アカウント）があるか確認します。無ければ、スマレジに申し込んで契約を作ります（トーホーとは**別の契約**になります）。
2. 契約ができたら、その契約の管理者アカウントでスマレジにログインできる状態にしておきます。
3. **契約ID**を控えます。契約IDは、アルファベットと数字の8文字ほどの文字列です（トーホーの契約IDは `sez093z1` の形）。ログイン後の画面の契約情報（または管理画面の「契約情報」）に表示されます。

### U1-2 管理システムのアプリを、LiveGateの契約にインストールする（アプリ連携）
管理システムがスマレジのデータを読み書きするのに使っている「アプリ」（スマレジ・デベロッパーズに登録済み）を、LiveGateの契約でも使えるようにします。**同じアプリを使うので、新しいアプリを作る必要はありません**（クライアントIDとシークレットは今のまま共通で使います）。
1. スマレジ・デベロッパーズ（https://developers.smaregi.dev/ ）に、いつものアカウント（有限会社トーホーエージェンシー）でログインします。
2. 管理システム用のアプリを開き、**他の契約でも使える設定**にします（アプリの「公開設定」や「利用契約の追加」にあたる項目。**非公開のまま、LiveGateの契約IDだけを許可する**のが理想です）。
3. LiveGate契約の管理者アカウントで、スマレジの管理画面から、このアプリを**インストール（利用開始・許可）**します。許可を求められる権限（スコープ）は、今のトーホーと同じものです（従業員の読み書き・事業所の読み取り・設定の読み取り・勤怠/シフトの読み書き）。
4. 許可の画面が出たら、**LiveGate契約でそのまま許可**します。
- うまく進めない場合（アプリが他の契約に出てこない、許可の画面が出ない等）は、その画面を送ってください。

### U1-3 契約IDを教える
- **LiveGateのスマレジ契約ID**をチャットで送ってください。
- 受け取ったら、こちら（担当D）で、管理システムがLiveGate契約に接続できるか（トークンが取れるか）を確認し、結果をお返しします。

### U1の完了チェック
- [ ] LiveGateのスマレジ・タイムカード契約がある
- [ ] 管理システムのアプリがLiveGate契約にインストール（許可）済み
- [ ] 契約IDを送った
- [ ] 担当Dから「接続できました」の連絡があった

## U2: LiveGateの契約に、店舗「黒霧屋 新横浜」だけを登録する（10/28まで）
スマレジの事業所（店舗）は、管理システムから自動では作れません（読み取りだけです）。**スマレジの画面で1つだけ作ってください**。
1. LiveGate契約の管理者アカウントでスマレジ・タイムカードの管理画面にログインします。
2. 事業所（店舗）の設定の画面で、**新しい事業所を追加**します。
   - 事業所名: **黒霧屋 新横浜**（トーホー側の名前と同じ表記にしてください。管理システムが同じ店舗として自動で結びつけやすくなります）
   - そのほかの項目（住所・営業時間など）は、分かる範囲で構いません。
3. 登録後、事業所の一覧に出ていることを確認します。**事業所IDまたはコード**（画面に表示される番号）が見える場合は、控えてください（こちらでも確認できます）。
4. 登録したら、チャットで「U2できました」と送ってください。こちらで、管理システムの店舗と自動で結びつけます。
- **スタッフ（従業員）はここでは登録しません。**
