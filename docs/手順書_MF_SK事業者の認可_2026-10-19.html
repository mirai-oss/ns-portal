手順書：SK（不動産）のMF（マネーフォワード）を、管理システムにつなぐ

作成：担当C（請求書・MF連携）／2026-10-19
やること：SKのMF事業者を「許可」して、請求書の仕訳をSKのMFに登録できるようにすること。
いま、SK宛の請求書（例：Cure Next ¥55,000）は、MFにつながっていないため承認画面の手前で止まっています（トーホーのMFに間違って入らないように止めています）。

ご自身でやることは、ブラウザでURLを開いて「許可」を押すことだけです（最大でも下の「A」「B」が必要なときだけ追加）。パスワード等をこちらに送る必要はありません。

先に確認してください

  • マネーフォワード クラウド会計に、SKの事業者があり、あなたのMFアカウントで開ける状態であること。
    （SKはまだMFを使っていない場合は、ここで止めて教えてください。MF以外の扱いを一緒に決めます）
  • 認可のとき、事業者は必ずSKを選ぶこと（トーホー・N-Style・LiveGateを選ぶと、SKとして誤ってつながります。間違えてもやり直せます）。

手順

  1. Chromeなどで、マネーフォワード クラウドにログインしておきます（いつもの管理者アカウント）。
  2. 下のURLを、同じブラウザの新しいタブに貼り付けて開きます。
    https://uuvsxzhpxtghojoubjcc.supabase.co/functions/v1/mf-oauth-authorize?tenant_id=sk&label=SK （URLは変更しないでください。tenant_id=sk が「SKとしてつなぐ」という意味です）
  3. マネーフォワードの許可の画面が出ます。
    ・事業者の選択が出たら SKの事業者 を選びます。
    ・内容（仕訳・勘定科目・部門などへのアクセス）を確認して 「許可する」 を押します。
  4. 画面に 「✅ マネーフォワード（SK）との連携が完了しました」 と出れば終了です（このタブは閉じてOK）。
  5. 終わったら、「SKを認可しました」とお知らせください。次は私の側で、つながったか（部門一覧が取れるか）を確認し、SK宛の請求書をSKのMFに入れる設定（コードの対応表）を追加します。この設定を入れるまでは、SK宛はまだ止まったままです（それで正常です）。

困ったとき

A．「アプリ連携権限が必要です。アプリポータルから権限を付与してください。」と赤く出た場合

→ 認可の失敗ではなく、あなたのMFアカウントに「アプリ連携」の権限がまだ無いという意味です（トーホー・N-Style・LiveGateのときと同じ作業です）。

  1. 赤い枠の青い文字 「アプリポータル」 をクリック（または https://portal.biz.moneyforward.com/ を開く）。
  2. 事業者 SK を選び、ユーザー・権限の管理を開きます。
  3. ご自身のアカウントに 「アプリ連携」の権限 をONにして保存します（変更できるのは、その事業者の管理者です）。
  4. もう一度、上の手順のURLを開いて「許可する」を押します。
  • B．事業者の選択にSKが出ない…そのMFアカウントにSKの権限がありません。SKの管理者権限があるアカウントでログインし直してください。
  • 間違った事業者を選んでしまった…もう一度上のURLを開き、今度はSKを選べば上書きされて正しくなります（ほかの会社のつながりには影響しません）。
  • エラー画面が出た…画面のスクリーンショットを送ってください。

このあとの流れ（こちらでやります）

  1. つながったか確認（SKの部門・勘定科目が読めること／他社の部門が混ざっていないこと）。
  2. SK宛の請求書をSKのMFに入れる対応表を追加（確認のうえ、Edge Function反映とpush）。
  3. SKのMFに足りない勘定科目・補助科目・部門があれば、一覧にしてお渡しします。
  4. 止まっているCure Next（¥55,000）の店舗を決めて、承認画面へ進めます。
会計期間（決算月）がほかの会社と違う場合があります。つなげたあと、こちらで日付が受け付けられるか確認します。
