手順書：tori-dashboard の Apps Script に「PL書き込みの鍵」と「作り直し機能」を入れる

これをすると、PLへの書き込みが同時に1つしか動かなくなり、補助科目がずれる原因がなくなります。あわせて、ずれてしまった分を請求書の記録から作り直す機能が使えるようになります。所要時間は10分ほどです。

コピーできないとき：枠をクリック → ⌘+A → ⌘+C。
大事：ファイル全部を置き換えるのではなく、下の3つの関数だけを入れ替え・追加します（本番のエディタとリポジトリの中身が少し違うことがあるため）。

やること

1. tori-dashboard（鳥一代ダッシュボード）のスプレッドシートを開き、拡張機能 → Apps Script を開きます。左のファイル一覧から Code.gs を開きます。
2. 上のほうにある function doGet(e) { のすぐ上に、下の ① withPlLock_ を貼り付けます（新しく足すだけ）。
① withPlLock_（新しい関数。doGetの上あたりに足す）
3. function handle(p) { から、その関数が終わる } までを選んで消し、下の ② handle を貼り付けます（丸ごと置き換え）。
（選びやすいように: function handle(p) { の行をクリック → 関数の終わりの } の行まで、Shiftを押しながらクリックして範囲を選びます）
② handle（今ある handle 関数を、丸ごとこの内容に置き換える）
4. ファイルのいちばん下に、下の ③ repairPlAutoRows を貼り付けます（新しく足すだけ）。
③ repairPlAutoRows（新しい関数。ファイルのどこか下のほうに足す）
5. ⌘+S で保存します。
6. 右上の デプロイ → デプロイを管理 → えんぴつ → 新バージョン → デプロイ を押します。（「新しいデプロイ」は選ばないでください。）
うまくいったか確認：デプロイのあと、私が動作確認用に応答を見ます。画面の ping の版が token-336h-v1-c19-pllock に変われば、貼り替えは成功です。

終わったら

「tori-dashboardのGASを更新しました」とお知らせください。次に、作り直す行の一覧を先に見ていただいて（実際には何も変えません）、よければ実行します。
