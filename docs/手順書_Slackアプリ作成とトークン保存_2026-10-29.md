# 手順書: Slack の「通知Bot」を作って、カギを安全にしまう（小学生でもできる版・2026-10-29）

## これは何をする手順？

会社の Slack に、**管理システムからお知らせを届けてくれるロボット（Bot）** を 1 つ作ります。
作ると「カギ」が 2 本もらえるので、それを**自分の Mac の中の秘密の引き出し**にしまいます。
最後に、お知らせを流す**部屋（チャンネル）** を作って、ロボットを部屋に入れます。

- かかる時間: **20 分くらい**
- 使うもの: **この MacBook**、会社の Slack に入れるメールアドレス
- やるのはあなたです。**Claude はカギを見ません。** しまったカギは、あとで Claude が「Supabase の金庫」にだけ移します。

### ぜったいのルール（これだけ守って！）

| ❌ やらない | ✅ かわりにこうする |
|---|---|
| カギ（`xoxb-` で始まる長い文字、Signing Secret）を**チャットに貼る** | この手順書の「ターミナルの 1 行」でファイルにしまう |
| カギをメモ帳・メール・スクショに残す | 残さない。もし残したら消す |
| 「From scratch」を選ぶ | 「**From an app manifest**」を選ぶ |

もし間違えてカギをどこかに貼ってしまっても大丈夫。最後の「困ったとき」に**作り直し方**があります。

---

## 全体の流れ（5 ステップ）

| ステップ | やること | 時間 |
|---|---|---|
| ① | Slack にログインして、ワークスペースがあるか確認 | 2 分 |
| ② | ロボット（アプリ）を作る（設定ファイルを貼るだけ） | 5 分 |
| ③ | カギ 2 本を Mac の秘密の引き出しにしまう | 5 分 |
| ④ | 部屋（チャンネル）を 6 つ作って、ロボットを入れる | 5 分 |
| ⑤ | 部屋の番号（チャンネル ID）を Claude に送る | 3 分 |

終わったら「③まで保存した。チャンネル ID はこれ」とチャットで教えてください。

---

## ステップ① Slack にログインして、ワークスペースを確認する（2 分）

**ワークスペース**＝会社ごとの Slack の「建物」のことです。

1. ブラウザ（Safari か Chrome）で **https://slack.com** を開く。
2. 右上の **「サインイン」** を押す。
3. メールアドレスを入れて **「メールでサインイン」**。メールに届いた **6 ケタの数字**を入れる。
4. 画面に「ワークスペース」が出たら、会社のものを選んで **「Slack を起動する」**。

**ワークスペースが 1 つも出てこないとき**（＝会社の Slack がまだ無い）:
1. **「新しいワークスペースを作成する」** を押す。
2. 「会社名またはチーム名」に会社名（例: `N-Style`）を入れて **「次へ」**。
3. 「あなたの名前」を入れて **「次へ」**。
4. 「メンバーを追加」は **「このステップをスキップする」** でOK（あとで足せます）。
5. 「チームで今取り組んでいること」は適当に（例: `通知`）→ **「次へ」**。
6. プランを聞かれたら **「無料で始める」**（無料でOK。ここではお金のかかる操作はしません）。

✅ **できたか確認**: 左上に会社名が出ていて、左側に「チャンネル」「ダイレクトメッセージ」が見えていればOK。

> **自分が「管理者」か確認**: 左上の会社名をクリック → 「ツールと設定」→「ワークスペースの設定」が押せれば管理者です。押せないときは、作った人に「管理者にして」と頼んでください。

## ステップ② ロボット（アプリ）を作る（5 分）

### ②-1 設定ファイルをコピーする

1. ブラウザで次を開く:
   **https://github.com/mirai-oss/ns-portal/blob/main/docs/slack/app-manifest.yaml**
2. ファイルの中身の右上にある **📋（Copy raw file）** のアイコンを押す。
   - 見つからないときは **「Raw」** ボタンを押す → 文字だけの画面になる → **⌘ + A**（全部選ぶ）→ **⌘ + C**（コピー）。

✅ これで設定ファイルがコピーされました（中にカギは入っていません。安心して貼れます）。

### ②-2 アプリを作る画面を開く

1. 新しいタブで **https://api.slack.com/apps** を開く。
2. 「Sign in」と出たら、ステップ①と同じメールでサインイン（同じ 6 ケタ方式）。
3. 右上の緑のボタン **「Create New App」**（新しいアプリを作る）を押す。
4. 小さい窓が出て 2 つ選べる。**下の「From an app manifest」** を押す。
   - ❌ 上の「From scratch」は押さない。

### ②-3 ワークスペースを選ぶ

1. 「Pick a workspace to develop your app in」の下の枠を押して、**会社のワークスペース**を選ぶ。
2. 右下の **「Next」**。

### ②-4 設定ファイルを貼る

1. 「Enter app manifest below」と書いてある画面になる。上に **「JSON」「YAML」** のタブがある → **「YAML」** を押す。
2. 枠の中に最初から何か書いてある → 枠の中をクリック → **⌘ + A** → **Delete** で全部消す。
3. **⌘ + V** で、②-1 でコピーしたものを貼る。
   - 一番上の行が `# =====` で始まっていて、`display_information:` という行が見えればOK。
4. 右下の **「Next」**。
5. 「Review summary & create your app」の画面になる。中身は読まなくてOK。右下の **「Create」**。

✅ **できたか確認**: 「Basic Information」と書かれた画面が開き、左上にアプリ名 **「N-Style 通知Bot」** が出ていればOK。

> ⚠️ 「Next」で赤いエラーが出たら: 貼り付けが途中で切れています。②-1 からやり直し（Raw → ⌘A → ⌘C）。

### ②-5 会社の Slack にロボットを入れる（インストール）

1. 同じ画面を少し下にスクロール → **「Install your app」** の中の **「Install to Workspace」** ボタンを押す。
   - 見つからないときは左のメニュー **「Install App」** を押す → **「Install to Workspace」**。
2. 「N-Style 通知Bot が ○○ ワークスペースへのアクセス権限をリクエストしています」という確認画面が出る → 一番下の **「許可する」**（英語なら「Allow」）。

✅ **できたか確認**: 画面に **「Bot User OAuth Token」** という文字と、`xoxb-` で始まる長い文字が出ます。**まだ何も触らない。次のステップでしまいます。**

## ステップ③ カギ 2 本を Mac の秘密の引き出しにしまう（5 分）

カギは「見ない・貼らない」で、**コピー → すぐにターミナルの 1 行でファイルに入れる**だけです。

### ③-0 ターミナルを開く（1 回だけ）

1. キーボードで **⌘ + スペース** を押す（検索窓が出る）。
2. `ターミナル` と打って **Enter**。黒か白の文字だけの窓が開けばOK。
3. この窓は③が終わるまで閉じないでおく。

### ③-1 カギ 1 本目「Bot User OAuth Token」

1. ブラウザ（②-5 の画面）で、`xoxb-` の文字の右にある **「Copy」** ボタンを押す。
   - 画面が変わってしまっていたら: 左メニュー **「OAuth & Permissions」** → 「OAuth Tokens」の中の **「Bot User OAuth Token」** の **「Copy」**。
2. **すぐに**ターミナルの窓をクリックして、下の 1 行をコピーして貼り（⌘ + V）、**Enter**。

```bash
mkdir -p ~/.config/ns-portal && pbpaste > ~/.config/ns-portal/slack_bot_token && chmod 600 ~/.config/ns-portal/slack_bot_token && echo "保存OK: $(wc -c < ~/.config/ns-portal/slack_bot_token) 文字" && pbcopy < /dev/null
```

> この 1 行の意味: 「秘密の引き出し（`~/.config/ns-portal`）を用意して → 今コピーしたものをファイル `slack_bot_token` に入れて → 自分だけ読める鍵をかけて → 何文字入ったか教えて → コピーした中身を消す」

✅ **できたか確認**: `保存OK:  50〜60 文字` のように出ればOK（数字は 50〜60 くらいならなんでも大丈夫）。
❌ `保存OK: 0 文字` や `1 文字` と出たら: コピーがうまくいっていません。1. の「Copy」からもう一度（Copy を押したあと、他のものをコピーしないでターミナルへ）。

### ③-2 カギ 2 本目「Signing Secret」

1. ブラウザで左メニューの一番上 **「Basic Information」** を押す。
2. 下にスクロールして **「App Credentials」** という箱を探す。
3. その中の **「Signing Secret」** の右の **「Show」** を押す → 文字が出る → その右の **📋（コピー）アイコン**を押す。
   - 文字を選んで ⌘ + C でもOK（最初から最後まで全部）。
4. **すぐに**ターミナルで、下の 1 行を貼って **Enter**。

```bash
pbpaste > ~/.config/ns-portal/slack_signing_secret && chmod 600 ~/.config/ns-portal/slack_signing_secret && echo "保存OK: $(wc -c < ~/.config/ns-portal/slack_signing_secret) 文字" && pbcopy < /dev/null
```

✅ **できたか確認**: `保存OK:  32 文字` くらいと出ればOK（31〜34 ならOK）。
❌ `0 文字` なら 3. からやり直し。

### ③-3 両方しまえたか最終チェック

ターミナルに下の 1 行を貼って **Enter**:

```bash
ls -l ~/.config/ns-portal/slack_bot_token ~/.config/ns-portal/slack_signing_secret
```

✅ 2 行出て、どちらも左端が `-rw-------` になっていればOK（＝自分だけ読める）。
これでカギは Mac の中だけにあります。**ターミナルは閉じてOK。** ブラウザのアプリ画面も閉じてOK。

## ステップ④ 部屋（チャンネル）を作って、ロボットを入れる（5 分）

Slack のアプリ（パソコン版でもブラウザ版でもOK）を開きます。

### ④-1 部屋を 6 つ作る（1 つ 30 秒）

1. 左側の **「チャンネル」** の文字の右にある **「＋」** を押す → **「チャンネルを作成する」**。
2. **「名前」** に下の表の名前を入れる（コピペでOK）。
3. **「公開範囲」** は表のとおり（**プライベート**＝入れた人だけ見える）。→ **「作成」**。
4. 「メンバーを追加する」と聞かれたら、**今は「スキップ」でOK**（あとで入れられます）。
5. これを 6 回くりかえす。

| 順番 | 名前（この通りに） | 公開範囲 | この部屋に流れるもの |
|---|---|---|---|
| 1 | `経営-レポート-g1` | プライベート | 本店・はなれ・芝・新橋の売上レポート |
| 2 | `経営-レポート-g2` | プライベート | 恵比寿・鶏武者川崎・黒霧屋新横浜の売上レポート |
| 3 | `経営-レポート-g3` | プライベート | 鶏武者新横浜・鶏武者川崎・黒霧屋新横浜の売上レポート |
| 4 | `本部-経理・監視` | プライベート | 毎日の取込結果・失敗・売上のズレ・請求書/入金 |
| 5 | `本部-開発・システム` | 公開 | システムのエラー・開発の連絡（テスト送信もここに来ます） |
| 6 | `本部-人事・入社` | プライベート | 入社・応募・退職の連絡（※作らない場合は 4 番に流れます） |

> 部屋の名前はあとで変えてもOK。システムは「名前」ではなく次の⑤の「番号」で部屋を見分けます。

### ④-2 それぞれの部屋にロボットを入れる

部屋を 1 つ開くごとに:

1. 下のメッセージを書く欄に、次をそのまま打って **Enter**:
   ```
   /invite @N-Style通知
   ```
   - 打っている途中で候補が出たら「N-Style通知」を選ぶ。
   - 「N-Style通知 をこのチャンネルに追加しますか？」と出たら **「追加する」**。
2. 「N-Style通知 がチャンネルに参加しました」と出ればOK。

> 別のやり方: 部屋の上の **部屋の名前をクリック** → 上のタブ **「インテグレーション」** → **「アプリを追加する」** → 「N-Style 通知Bot」の **「追加」**。

✅ **できたか確認**: 6 つ（または 5 つ）の部屋すべてで「参加しました」が出た。

## ステップ⑤ 部屋の番号（チャンネル ID）を Claude に送る（3 分）

**チャンネル ID** は `C` で始まる 9〜11 文字の番号で、**秘密ではありません**（チャットに貼ってOK）。

部屋を 1 つ開くごとに:

1. 画面の上の **部屋の名前をクリック**（小さい窓が開く）。
2. **「概要」** タブのまま、**一番下までスクロール**。
3. 一番下に **「チャンネル ID: C0XXXXXXXXX」** とあり、右に **📋 コピー**アイコンがある → 押す。
4. チャットに貼る。

6 つ分そろったら、チャットにこの形で送ってください（左側はこの通り、右側に番号）:

```
keiei.report.g1 = C0.........
keiei.report.g2 = C0.........
keiei.report.g3 = C0.........
hq.keiri_kanshi = C0.........
hq.dev_system   = C0.........
hq.jinji        = C0.........   ← 6番の部屋を作った場合だけ
```

## おわりに: チャットで教えてほしいこと

1. 「**③まで保存した**」（カギ 2 本がしまえた）
2. **チャンネル ID の表**（⑤のもの）
3. 決めてほしいこと 2 つ
   - 6 番の部屋「本部-人事・入社」を**作った／作らない**
   - 経営-レポート g1・g2・g3 に**それぞれ誰を入れるか**（名前でOK。入れるのはあなたが Slack でやります）

ここから先は Claude が、カギを Supabase の金庫に移す → データベースの準備（内容を先に報告して OK をもらってから）→ ロボットを動かす → 「本部-開発・システム」にテスト送信 1 通、まで進めます。

## 困ったとき

| こうなった | こうする |
|---|---|
| 「Create New App」が押せない／ワークスペースが選べない | あなたがその Slack の管理者ではありません。ステップ①の「管理者か確認」を見て、管理者にしてもらう |
| 設定ファイルを貼って「Next」で赤いエラー | 貼り付けが欠けています。②-1 の「Raw → ⌘A → ⌘C」からやり直し |
| 「許可する」の画面が出ない | 左メニュー「Install App」→「Install to Workspace」をもう一度 |
| 「保存OK: 0 文字」 | Copy ボタンを押してからターミナルに行くまでに、別のものをコピーしてしまった。もう一度 Copy → すぐターミナル |
| ターミナルに貼ったら `command not found` | 1 行が途中で切れています。グレーの箱の右上のコピーボタンで**1 行まるごと**コピーして貼り直す |
| **カギをチャットやメモに貼ってしまった** | 焦らなくて大丈夫。api.slack.com/apps → N-Style 通知Bot → 「OAuth & Permissions」→ 一番下の **「Revoke All Tokens」**（全部無効にする）→ 同じ画面の上の **「Reinstall to Workspace」**→「許可する」→ 新しいカギが出るので ③-1 をやり直す。Signing Secret は「Basic Information」→ Signing Secret の **「Regenerate」** → ③-2 をやり直す |
| `/invite` で「N-Style通知」が候補に出ない | ②-5 のインストールができていません。②-5 をやり直す |
| チャンネル ID が見つからない | 部屋の名前をクリック → 「概要」タブ → 一番下までスクロール。それでも無ければ、部屋のリンク（名前を右クリック→「リンクをコピー」）を送ってくれれば Claude が読み取ります |
