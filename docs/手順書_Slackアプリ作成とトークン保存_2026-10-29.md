# 手順書: Slack アプリ（通知Bot）の作成とトークンの保存（2026-10-29）

**やること**: Slack に「N-Style 通知Bot」を 1 つ作って、鍵（トークン）を自分の Mac に安全に保存し、チャンネルを作る。
**所要**: 15 分くらい。**必要なもの**: Slack ワークスペースの管理者権限、この Mac（MacBook）。
**絶対にしないこと**: トークン（`xoxb-` で始まる文字列・Signing Secret）を**チャットに貼らない**、メモアプリに残さない。コピーしたらすぐに下のコマンドで保存する。

---

## 0. ワークスペースの確認

1. ブラウザで https://slack.com にログインする。
2. 会社のワークスペースが**まだ無い**ときは「ワークスペースを作成」で作る（名前は会社名で OK・あとで変えられる）。
3. 自分が**管理者**であることを確認する（左上のワークスペース名 → 「設定と管理」が見えれば OK）。

> プランについて: 無料プランは「90 日より前のメッセージが見えなくなる」制限があります。通知の過去ログは管理システム側の台帳に残るので、まずは無料で始めて問題ありません。

---

## 1. アプリを作る（マニフェストを貼るだけ）

1. ブラウザで **https://api.slack.com/apps** を開く。
2. 右上の緑のボタン **「Create New App」** を押す。
3. 2 つ出るうち **「From a manifest」**（マニフェストから）を選ぶ。
4. 「Pick a workspace」で会社のワークスペースを選び **Next**。
5. タブで **YAML** を選び、枠の中身を全部消して、次のファイルの中身を**丸ごと**貼り付ける:
   `ns-portal/docs/slack/app-manifest.yaml`（GitHub で開いて「Raw」→ 全選択 → コピー）
6. **Next** → 内容の確認画面が出るので **Create**。
7. できたアプリの画面（Basic Information）が開けば成功。

> 迷ったら: 「From scratch」ではなく「From a manifest」です。マニフェストには鍵は入っていません。

---

## 2. ワークスペースにインストールする

1. 左メニュー **「Install App」**（または Basic Information の「Install to Workspace」）を押す。
2. 許可の確認画面が出るので **「許可する（Allow）」**。
3. 画面に **「Bot User OAuth Token」** という欄が出て、`xoxb-` で始まる長い文字列が表示される。**まだコピーしない**（次の手順で、画面を見ながらやる）。

---

## 3. トークンを Mac に保存する（コピー → すぐ保存）

### 3-1. Bot Token

1. 手順 2 の画面で **「Copy」** ボタンを押す（`xoxb-…` がクリップボードに入る。画面には出さなくて OK）。
2. Mac の **ターミナル** を開いて、次を 1 行ずつ実行する（クリップボードの中身をそのままファイルに書き、自分だけ読める権限にする）:

```bash
mkdir -p ~/.config/ns-portal && pbpaste > ~/.config/ns-portal/slack_bot_token && chmod 600 ~/.config/ns-portal/slack_bot_token && echo "保存OK: $(wc -c < ~/.config/ns-portal/slack_bot_token) 文字"
```

3. 「保存OK: 50〜60 文字」くらいと出れば成功（0 文字なら Copy からやり直し）。
4. クリップボードを空にする:

```bash
pbcopy < /dev/null
```

### 3-2. Signing Secret（ボタン操作の本人確認に使う鍵）

1. 左メニュー **「Basic Information」** → 下の方 **「App Credentials」** → **「Signing Secret」** の **Show** → **Copy**。
2. ターミナルで:

```bash
pbpaste > ~/.config/ns-portal/slack_signing_secret && chmod 600 ~/.config/ns-portal/slack_signing_secret && echo "保存OK: $(wc -c < ~/.config/ns-portal/slack_signing_secret) 文字" && pbcopy < /dev/null
```

3. 「保存OK: 32 文字」くらいと出れば成功。

> ここまでで鍵は `~/.config/ns-portal/` の中だけにあります。この後は司令塔（Claude）が、このファイルから Supabase の Edge Function にだけ投入します。チャットには一切流しません。

---

## 4. チャンネルを作って Bot を入れる

Slack アプリ（デスクトップ or ブラウザ）で、次のチャンネルを作る（「チャンネルを作成」→ 名前 → 公開 or 非公開）。

| チャンネル名（変更可） | 公開/非公開のおすすめ | 入れる人 |
|---|---|---|
| `#経営-レポート-g1` | 非公開 | 本店・はなれ・芝・新橋の数字を見てよい人 |
| `#経営-レポート-g2` | 非公開 | 恵比寿・鶏武者川崎・黒霧屋新横浜の数字を見てよい人 |
| `#経営-レポート-g3` | 非公開 | 鶏武者新横浜・鶏武者川崎・黒霧屋新横浜の数字を見てよい人 |
| `#本部-経理・監視` | 非公開 | 経理・本部 |
| `#本部-開発・システム` | 公開でも可 | 開発・本部 |
| `#本部-人事・入社`（おすすめ） | 非公開 | 人事・本部（作らない場合は経理・監視に入社通知が流れます） |

各チャンネルで、メッセージ欄に次を打って Enter（Bot を招待する）:

```
/invite @N-Style通知
```

---

## 5. チャンネル ID を送る（これは秘密ではありません）

1. チャンネルを開き、**上のチャンネル名をクリック** → 出てきた画面を**一番下までスクロール** → **「チャンネル ID: C0XXXXXXXXX」** をコピー。
2. 6 つ分（4 つ目を作らない場合は 5 つ）を、チャットにこの形で送ってください:

```
keiei.report.g1 = C0.........
keiei.report.g2 = C0.........
keiei.report.g3 = C0.........
hq.keiri_kanshi = C0.........
hq.dev_system   = C0.........
hq.jinji        = C0.........   （作った場合）
```

---

## 6. 終わったら

「Slack の 3-2 まで保存した・チャンネル ID はこれ」とチャットで連絡してください。以降は司令塔側で、

1. 鍵を Edge Function の secret に投入（`~/.config/ns-portal/` のファイルから。チャットには出さない）
2. SQL（`2026-10-29_slack_notify_phase1.sql`）の適用（事前に内容を報告して承認をもらう）
3. `notify-slack` のデプロイと、`#本部-開発・システム` へのテスト送信 1 通

まで進めます。テスト送信が届いたら Phase 1-a（nippo 系）から並行送信を始めます。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「Create New App」が押せない／ワークスペースが選べない | そのワークスペースの管理者ではない。管理者にこの手順書を渡すか、自分を管理者にしてもらう |
| マニフェスト貼り付けでエラー | YAML の先頭に余計な空白・全角スペースが入っている。もう一度 Raw から全選択してコピー |
| 「保存OK: 0 文字」 | Copy ボタンを押してからターミナルに戻るまでに別のものをコピーした。Copy からやり直し |
| トークンを間違えてチャットに貼ってしまった | Slack の OAuth & Permissions → 「Revoke」で無効化 → 「Reinstall」で新しいトークンを発行 → 3-1 をやり直す |
| Bot をチャンネルに入れ忘れた | 公開チャンネルなら送れる設定（`chat:write.public`）。非公開は `/invite` が必要 |
