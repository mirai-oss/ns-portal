## 結論（先に3行）
1. **仕入高の「速報」は使える**: 毎朝06:45にインフォマートの仕入見込（発注〜受領・店舗合計・日次）を取り込み、直近は連続成功。月の途中でも店舗別の「ここまでの仕入」が分かる（鮮度＝1日遅れ。翌日納品の発注分まで先に入る）。
2. **ただし「取引先別の速報」は無い**ので、請求書が来た取引先分だけを速報から差し引く置換はできない。**置換は店舗単位（その月の請求書が出そろったら店舗合計ごと実額へ）**が現実的（TK-222と同じ考え方）。
3. **重複が2つある**: ①担当Cの「仕入高差額調整」（pl_entriesに調整行）と TK-222（kd側で置換）は**同じ目的の別方式**で、両方動くと二重に調整される。②TK-222は実装済みだが**スイッチ未設定＝現在は何も置換されていない**。着地予想PLの設計に入れる前に、どちらかに一本化を決めてください（§2）。

## ③ 店舗別のドライバー（着地予想の算定）
**仕入高は売上に連動する**（飲食の原価率）。直近の月次の原価率（速報÷売上）は店舗ごとにほぼ一定で、店舗別の率が強いドライバーになります（4〜9月・月ごとのばらつき）:

| 店舗 | 原価率の目安（4〜9月） | ばらつき（標準偏差・ポイント） | 補足 |
|---|---|---|---|
| 鳥一代 恵比寿 | 約20.6% | 0.6 | 最も安定 |
| 鳥一代 はなれ | 約27.4% | 0.7 | 安定 |
| 鶏武者 新横浜 | 約26.0% | 1.0 | 安定 |
| 黒霧屋 新横浜 | 約19.3% | 1.7 | 11/1から運営変更（下記④） |
| 鳥一代 新橋 | 約22.4% | 1.5 | |
| 芝の鳥一代 | 約31.0% | 1.9 | |
| 鶏武者 川崎店 | 約30.4% | 2.5 | 9月に35%台へ上昇 |
| 鳥一代 本店 | 約28.9% | 3.1 | **9月・10月に35%前後へ上昇**（それ以前は27%台）。直近3か月平均では実態に追いつかない |
- 推奨method: **`weighted_ratio`（直近3か月率と前年同月率の加重平均）×当月売上見込**。本店・川崎のように最近水準が変わった店舗は、直近1〜2か月を重くする重み（店舗別に設定）。恵比寿・はなれ・新横浜は `avg_3m_ratio` で足りる。
- **月の途中の見方（preview）**: ここまでの速報（当月累計）＋残り日数の見込（売上見込×原価率）。**10月（月途中）の率は多くの店舗で平均より1〜3ポイント高め**に出ている（発注〜受領ベースで、売上より先に仕入が計上されるため）。月の途中は「速報累計÷売上累計」をそのまま率にせず、前月までの率で補正するか、月の終盤（20日以降）に切り替える。
- 4店舗（業務委託）は原価0が正常なので、ルール対象外（精算書ルートの確定額が出るまで空欄＝「精算書反映待ち」）。
