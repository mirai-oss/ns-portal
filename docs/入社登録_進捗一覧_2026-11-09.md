## 4. 駅すぱあと API 申請前確認（②の 6 点・2026-11-09 公開資料より）

| 確認項目 | 結果 |
|---|---|
| 住所からの周辺駅検索 | ○ `GET /v1/json/address/station`（住所＋半径）と `/geo/station`（緯度経度）。経路 API の viaList にも住所を直接指定可 |
| 自宅→店舗の合理的な通勤経路 | △ 時刻（date/time）・探索種別（平均待ち時間/ダイヤ）・交通種別（conditionDetail でバス等の利用有無）・並べ替え（time/price/transfer/teiki）は可。**乗換回数の上限・徒歩距離の上限の専用パラメータは無し**（応答の timeWalk・乗換回数で自分で絞る） |
| 片道・往復運賃 | ○ 応答 Price（Fare: Oneway/Round）。往復割引はJR・空路のみ、無ければ片道×2 |
| 定期代 | ○ Teiki1/3/6/12（Oneway）。払戻・分割計算 API もあり |
| バスを含む経路 | ○ 路線バス・高速バス対応（plain の bus、extreme の conditionDetail、bus 専用探索）。**フリープランは鉄道・航空のみ**。バスのダイヤ利用は事業者ライセンスが別途必要（平均待ち時間探索なら不要） |
