## 1. ①給与明細→MF仕訳＋明細添付（項目1）

### 1.1 確認結果（先に答え）
- **給与明細の中身は取れる**: `timecard.salaries:read`で支給内訳（基本給・固定残業代・通勤手当など）の取得実績あり（青山純さんの実データで検証済み）。**控除側（社会保険・所得税等）の内訳と、スマレジが発行する明細PDFそのものがAPIで取れるかは未確認**（着手時の最初の調査項目）
- **MFへの仕訳入力はできる**: `mf-journal`の`create`（複合仕訳=1本の仕訳に複数明細行）で技術的に可能
- **明細の添付もできる見込み**: 証憑API（`/api/v3/vouchers`）で仕訳にファイル添付済みの実績あり。スマレジPDFが取れない場合は、取得済みデータから明細PDFを自社生成して添付する代替案あり

### 1.2 実装案
1. 月次（給与確定後）に、`sf_payroll_sync`＋`sf_payroll_allocations`（店舗按分）から**法人×月の給与仕訳ドラフト**を組み立てる（借方: 給料手当（部門=店舗按分）／通勤費… 貸方: 未払金 or 預り金…※科目はQ2）
2. 「AI=下書き・人=承認」の既存原則どおり、**画面で内容確認→ボタンでMFへ登録**（自動サイレント登録はしない）
3. 登録成功後、**従業員ごとの給与明細（PDF）を証憑として同じ仕訳に添付**（最大件数・容量制限があるため、人数が多い月は結合PDF1本にする案が現実的）
4. 置き場所: 「会計」タブ（§3）内の「給与仕訳」メニュー

## 2. ②インフォマート（項目4）

### 2.1 やること（ユーザー要望の分解）
| # | 内容 | 難度 |
|---|---|---|
| a | **発注明細をBigQueryへ蓄積**（今は店舗別・日別合計のみ→明細粒度に） | 中（API契約が前提） |
| b | 発注実績・使用金額の分析をBQから取得できるように | 小（aの後） |
| c | **請求書PDFをMFに証憑添付**して仕訳登録 | 小（既存基盤で可） |
| d | **振込先情報→銀行の総合振込CSVを自動生成**（人間は確認してアップロード・振込実行だけ） | 中（銀行フォーマット確定が前提） |
| e | ポータルに**「会計」タブ**を新設して一元化 | 小 |

### 2.2 実装案
- **API**: インフォマート公式API（BtoBプラットフォーム）を利用（ユーザー提示のリファレンスを確認済み）。**利用には申込み・契約が必要な可能性が高い**（Q4）。契約が下りるまでは現行スクレイピング（infomart-siire.js）の拡張で明細CSVが取れないかを並行調査
- **BQ**: 新テーブル`stg_infomart_order`（発注日×店舗×取引先×品目×数量×金額）。日次でns-daily-import or GitHub Actionsから投入
- **振込CSV**: 請求データ（支払先・口座・金額・支払期日）から、指定銀行の**総合振込フォーマットCSV**を生成して「会計」タブからダウンロード。**振込の実行は絶対に自動化しない**（生成→人間が確認→ネットバンキングにアップロード→人間が承認、まで）
- **重複防止**: MF仕訳登録・振込CSVとも「どの請求書を処理済みか」をDBで管理（invoicesの`mf_journal_id`と同型）

## 4. ユーザーへの質問

- **Q1（給与・法人）**: 給与仕訳はどの事業者（法人）のMFに入れますか？（トーホー／N-Style／両方=従業員ごとに振り分け。振り分けが必要なら、誰がどちらの法人所属かの分け方も）
- **Q2（給与・科目）**: 今、給与はMFにどう入力していますか？（過去の給与仕訳を参考にこちらで科目・形を提案→確認してもらう進め方でよいか。それとも「この形で入れて」という指定がありますか）
- **Q3（給与・明細添付）**: 添付したい「個人の給与明細」は、スマレジの明細PDFそのままが必要ですか？（APIで取れない場合、取得済みデータから同内容のPDFを自社生成して添付する形でもよいか。またMFの証憑は経理担当も見られるため、全従業員分の明細を添付してよいかの確認）
- **Q4（インフォマート）**: インフォマートAPIの利用申込み・契約はしていますか？（未契約なら申込みが最初のステップになります。申込みの窓口・条件はこちらで調べて手順書にします）
- **Q5（振込CSV）**: 振込に使う銀行とサービス名を教えてください（例: PayPay銀行の総合振込／○○銀行のビジネスダイレクト等。そのフォーマットに合わせてCSVを作ります。振込元口座が複数ならその一覧も）
- **Q6（会計タブ）**: §3の「🧾会計」グループ新設の形でよいですか？（既存の「請求書メール」もこの中に移動します）
