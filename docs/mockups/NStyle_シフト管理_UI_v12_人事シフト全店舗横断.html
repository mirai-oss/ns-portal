計算ロジック（UI説明用）

① 基準売上 = 選択ルールにより「売上目標」と「昨年同週同曜日」を参照
② PA使用可能人件費 = 基準売上 × PA目標人件費率
③ 加重平均PA時給 = 通常時給 + 22時以降の深夜割増をシフト構成比で加重
④ 適正PA時間 = PA使用可能人件費 ÷ 加重平均PA時給
⑤ 推奨調整時間 = 適正PA時間 − 現在PA予定時間
