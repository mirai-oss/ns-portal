# 手順: PayPay 銀行の「WEB総振」を読むロボット（段階 1）

下書き: 2026-11-13。**まだ 1 回も動かしていません**（文法の確認と、守りの部品の確認だけ済み）。はじめて動かすときは、画面を見ながら・作った人（Claude）と一緒に。

---

## これは何をするもの

ロボットが、いつもの入金取得と **同じログイン** で PayPay 銀行に入り、メニューの **「WEB総振」を 1 回だけ開いて**、その画面の「形」をメモして、ログアウトします。それだけです。

| すること | しないこと |
|---|---|
| ログイン（毎日のロボットと同じ処理・同じ ID） | 振込・依頼・承認・予約・取消・登録・変更（**ボタンを押せない作り**にしてあります） |
| メニューの「WEB総振」を 1 回押す | 文字を入力する（ログインのとき以外は、何も入力しません） |
| 開いた画面の形を、伏せ字でメモする | 口座を選ぶ・ファイルを保存する・画面の写真をとる |
| ログアウト | 暗証番号・トークン・ワンタイムを入れる（聞かれたら、何もせずに止まります） |

- メモに残るのは、画面の名前・見出し・ボタンの文字・表の形だけです。口座番号・名前・金額は `＊` や「カナ」に置きかわります。
- メモの場所: `~/.ns-payroll-inspect/`（リポジトリの外。本人だけが読めます）。

## ⛔ 動かしてはいけないとき

- **13:45〜14:40**（毎日の入金取得と重なります。この時間は、ロボットが自分で止まります）
- 毎日のロボットが動いているとき（ロボットが自分で止まります）
- PayPay 銀行のブラウザ（ロボット用の画面）が、ほかに開いているとき（ロボットが自分で止まります）

## はじめる前の準備（Claude がやります。承認のあと）

1. 下書きの 3 つのファイルを置く: `tasks/paypay-sofuri.js`・`lib/sofuri-guard.js`・`lib/sofuri-mask.js`
2. `tasks/paypay-bank.js` に **1 行だけ**足す（`paypay-bank.export.patch`。ログインの処理を貸し出すための 1 行。毎日のロボットの動きは変わりません）
3. `dispatch.js` には **登録しません**（自動では動きません。手で 1 回ずつ動かします）

- 成功の見分け方: 文字を打つ画面が出る。

### 2. 時計を見る

- やること: いまの時刻が **13:45〜14:40 ではない**ことを確かめる。
- 成功の見分け方: その時間でなければ OK。

### 3. 動かす（この 1 行だけ）

- やること: 次の 1 行をコピーして、ターミナルに貼り、Enter を押す。

```
cd /Users/mirai/ns-daily-import && STAGE=1 node tasks/paypay-sofuri.js
```

- 成功の見分け方:
  - ターミナルに `段階 1 を始めます（読むだけ）` と `記録の場所: …` が出る。
  - ロボット用のブラウザが開いて、PayPay 銀行のログイン画面 → メニューの画面へ、**ひとりでに**進む。
- **このあいだ、ブラウザには触らないでください**（マウスもキーボードも）。

### 4. 見ているだけ（1〜2 分）

- やること: 何もしない。ターミナルの文字を見る。
- 成功の見分け方: 次の順に出る。
  1. `（既存のログイン）ログイン成功・口座選択画面`
  2. `メニューの「WEB総振」を開きます`
  3. `ログアウトしました`
  4. `結果: ok（「WEB総振」の画面の構造を記録しました）／ 画面の記録 ◯ 件 ／ 記録に残っている 4 桁以上の数字: 0 件（OK）`
  5. `終わりました: 成功`
- ブラウザは、ひとりでに閉じます。

### 5. 知らせる

- やること: 「終わりました」と、ターミナルの最後の 2 行（`結果:` と `終わりました:`）を伝える。
- メモのファイルは Claude が読みます（場所は、ターミナルの `記録の場所:` の行）。

## 「成功」以外が出たとき（どれも、何も押さずに止まっています）

| ターミナルの文字 | 意味 | どうする |
|---|---|---|
| `結果: human_required` | 合言葉・暗証番号・トークン・ワンタイムを聞かれた。ロボットは **何も入力せず・何も押さずに**やめました（ログアウトもしていません） | そのまま知らせる。次の毎日のロボットは「上書きログイン」で入り直すので、放っておいて大丈夫です |
| `結果: entry_not_found` | メニューに、決めた形の「WEB総振」が見つからなかった | そのまま知らせる（Claude がメモを見て調べます） |
| `結果: click_blocked` | 押そうとした相手が、決めた形とちがった。**守りが止めました**（押していません） | そのまま知らせる |
| `結果: login_failed` | ログインのあと、いつもの画面に進めなかった | そのまま知らせる。毎日の入金取得も同じ理由で止まっているかもしれません |
| `止まりました: 13:45〜14:40 は…` | 動かしてはいけない時間だった | 時間をずらして、手順 3 からやり直す |
| `止まりました: 毎日のタスク（dispatch.js）が実行中です…` | 毎日のロボットが動いている | 5 分待って、手順 3 からやり直す |
| `止まりました: 同じプロファイル…のブラウザが開いています…` | ロボット用のブラウザが、ほかに開いている | そのブラウザを閉じて、手順 3 からやり直す |
| `止まりました: paypay-bank.js から login() を借りられません…` | 準備の 2 がまだ | Claude に知らせる |
| `記録に残っている 4 桁以上の数字: ◯ 件（★この記録は渡さないでください）` | 伏せもれがあった | そのメモは、だれにも渡さない。知らせる |

## 途中で止めたいとき

- やること: ターミナルをクリックして、**control を押しながら C** を 1 回押す。
- 成功の見分け方: ブラウザが閉じて、ターミナルに次の入力待ち（`%` や `$`）が出る。
- ブラウザの × で閉じても止まります。
- 途中で止めると、ログアウトしていないことがあります。次の毎日のロボットは「上書きログイン」で入り直すので、そのままで大丈夫です。
- ブラウザに「OK／キャンセル」の小さい窓が出ても、**人は押さない**でください（ロボットが必ず「キャンセル」を選びます）。

## この先（段階 2 以降）

段階 1 のメモを見て、「照会・明細・結果・履歴・PDF／CSV」の入口の名前と形を決めてから、1 つずつ足します。足すまでは、ロボットは「WEB総振」より先へ進めません（`STAGE=2` と打っても、`止まりました: いまは STAGE=1 だけ用意しています…` と出て、ブラウザを開かずに止まります）。

「振込明細照会」は、名前に「振込」が入るので、いまの守りでは押せません。押せるようにするかどうかは、段階 1 のメモを見たあとで、あらためて決めます。
