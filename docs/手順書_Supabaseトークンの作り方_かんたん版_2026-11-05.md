# かんたん手順書 Supabase（スーパーベース）の「合い言葉（トークン）」を作る — 2026-11-05

**やること:** 「合い言葉」を1つ作って、このチャットに貼り付けます。
**時間:** 5分くらい。**終わったら、その合い言葉は消します**（最後の「7」）。

> 合い言葉（トークン）とは、Claude が「お願いされた作業をしてもいいよ」と Supabase に見せる、1回だけ使うカギです。
> 作れるのは、あなたのアカウントだけです。

---

## 1. ページを開く
1. パソコンのブラウザ（Chrome など）を開きます。
2. 下の文字をコピーして、いちばん上の細長い四角（アドレス欄）に貼って、`Enter` を押します。

   `https://supabase.com/dashboard/account/tokens`

3. ログインの画面が出たら、いつもの Supabase のアカウントでログインします。

## 2. 「新しく作る」ボタンを押す
- 画面にある、緑色のボタン **「Generate new token」** を押します。
- 入力の画面が出ます。

## 3. 入力する（上から順番に）

| 画面の文字 | やること |
|---|---|
| **Name**（名前） | `claude-1105` と入力します（なんでも大丈夫です） |
| **Expires in**（いつまで使えるか） | 開いて **「1 day」** か「24 hours」を選びます。無ければいちばん短いものを選びます |
| **Resource access** | 「Project」の丸が選ばれたままにします（何もしなくてOK） |
| **Select an organization** | 開いて、出てきたものを選びます（1つだけのはずです） |
| **Select a project** | 開いて、**`uuvsxzhpxtghojoubjcc`** と書いてあるものを選びます（名前は「nippo」など） |
| **Permissions**（できること） | 次の「4」を見てください |

## 4. 「できること」を決める
1. **Permissions** のところに、「Preset」と書いてある四角があります。そこを押します。
2. **「Full access」**（または「Admin」）があれば、それを選びます。これで終わりです。
3. 見つからないときは、「Database」と「Application services」と書いてある灰色の帯を押して開き、中の項目を **ぜんぶ「Write」** にします。

## 5. 作る
1. 右下の緑のボタン **「Review access」** を押します。
2. 内容が出るので、右下の **「Generate token」** を押します。

## 6. コピーして、チャットに貼る
1. **`sbp_`** で始まる、長い文字が出ます。
   **この文字は、この画面でしか見られません。** 閉じる前に、必ずコピーしてください。
2. 文字の右にある、四角が2つ重なったマーク（コピーボタン）を押します。
3. Claude とのこのチャットに戻って、入力するところに `Command + V` で貼り付けて、送ります。
   - 貼る文字は **`sbp_` から最後まで、全部** です。
   - 前後に、ほかの文字は付けなくて大丈夫です。

> もし間違えて画面を閉じてしまったら、「2」からやり直せば大丈夫です（失敗しても何も壊れません）。

## 7. 終わったら、合い言葉を消す（大事）
Claude が「作業が終わりました」と伝えたら、次のようにして消します。
1. もう一度、`https://supabase.com/dashboard/account/tokens` を開きます。
2. さっき作った `claude-1105` の右にある **「Revoke」**（取り消し）を押します。
3. 確認が出たら、もう一度 **「Revoke」** を押します。

これで、その合い言葉は二度と使えなくなります。

## うまくいかないとき
| こまったこと | こうする |
|---|---|
| 「Generate new token」が見つからない | 画面の左にあるメニューの「Access Tokens」を押します |
| 「Select a project」に何も出ない | 先に「Select an organization」を選びます |
| 「Full access」が見つからない | 「4」の3のとおり、「Database」と「Application services」をぜんぶ「Write」にします |
| どれが正しいプロジェクトか分からない | **`uuvsxzhpxtghojoubjcc`** と書いてあるものを選びます |
| あとで Claude から「権限が足りません」と言われた | 「3」からもう一度作って、「4」の項目をぜんぶ「Write」にします |

## 安心してください
- Claude が使うのは、**今回のお願い（請求書の判定の修正を本番に反映する）だけ**です。
- 使い終わったら「7」で消すので、あとから使われることはありません。
