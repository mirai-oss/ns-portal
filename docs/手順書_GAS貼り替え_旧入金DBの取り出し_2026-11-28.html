手順書: 旧入金DBの取り出し用GASの貼り替え（Code.gs を丸ごと貼る・いつもの a7pg と同じやり方）

所要 5 分。貼る場所は「【サーバー】ダッシュボード(v2・バージョン上限のため移行)」のスプレッドシートに付いている Apps Script の Code.gs です（前回の a7pg と同じ場所）。
2026-11-28 更新: 追加の処理は Code.gs の末尾に入れました（ファイルを増やさない）。Code.gs 1 ファイルを丸ごと貼れば足ります。
どの GAS か（迷ったら）：
・貼る先＝スプレッドシート「【サーバー】ダッシュボード(v2・バージョン上限のため移行)」→ メニュー「拡張機能」→「Apps Script」→ ファイル「Code.gs」。
・ほかの GAS（精算ダッシュボード・売上DB のスクリプト・日報など）は触りません。売上DB（入金DB のあるスプレッドシート）に付いた Apps Script でもありません。
・見分け方：開いた Code.gs の中を ⌘F で token-336h-v1-c19-pllock-a7pg と検索して 1 件見つかれば、正しい場所です。

手順（1つずつ）

手順1：コードをコピーする

  1. Finder で Claude → tori-dashboard → gas を開く（最新にしてあります。私が main に入れて、この Mac のフォルダも更新済み）。
  2. Code.gs を 右クリック → このアプリケーションで開く → テキストエディット。
  3. ⌘F で a7pg-lde1 と検索して、1 件見つかることを確認（見つからなければ、まだ古いファイル。私に連絡）。
  4. ⌘A（全部選ぶ）→ ⌘C（コピー）。何も変えずに閉じる。
    成功の見分け方：⌘F で a7pg-lde1 が 1 件見つかった。

手順2：Apps Script に貼る

  1. Chrome で スプレッドシート「【サーバー】ダッシュボード(v2・バージョン上限のため移行)」を開く。
  2. 上のメニュー「拡張機能」→「Apps Script」。
  3. 左のファイル一覧で「Code.gs」をクリック（他のファイルは触らない。前回、別ファイル LegacyDepositExport を足していたら、そのファイルは消してください：同じ名前の関数が 2 つになるのを避けるため）。
  4. 右の編集画面の中をクリック → ⌘A → Delete → ⌘V。
  5. ⌘S で保存。
    成功の見分け方：赤いエラーが出ない。貼ったあと、⌘F で a7pg-lde1 が 1 件見つかる。

手順3：デプロイを更新する（「新しいデプロイ」は押さない）

  1. 右上の青い「デプロイ」→「デプロイを管理」。
  2. 出てきた窓の右上の 鉛筆（編集） をクリック。
  3. 「バージョン」のプルダウンを「新バージョン」にする。
  4. 説明の欄に lde1 と入れる。
  5. 「デプロイ」→「完了」。
    成功の見分け方：「デプロイを管理」で、バージョンの数字が 1 つ増えた。

手順4：私に「貼替した」と一言

私が、ping のバージョンが …-lde1 になったこと、6列と備考が取れること、権限、既存の入金取込への影響を確認します。

うまくいかないとき

症状原因と直し方
私の確認で「ping が古いまま（…a7pg）」／「unknown action」と出る①保存はしたが「新バージョン」でデプロイしていない（保存だけでは本番に反映されません）②別の Apps Script に貼った（上の「どの GAS か」を確認）③「新しいデプロイ」を押して、別の URL ができた（この場合は私に連絡。URL を元に戻す必要があります）
貼ったあと赤いエラー貼る範囲が途中で切れている可能性。手順2をやり直す（⌘A → Delete → ⌘V）

戻し方（問題があったとき）

  1. 「デプロイを管理」→ 鉛筆 → 「バージョン」で、直前の古いバージョンを選ぶ → 「デプロイ」。
