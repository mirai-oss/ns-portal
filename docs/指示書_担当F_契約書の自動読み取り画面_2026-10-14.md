### API
- 入力: `{ "document_id": "<info.documents.id>", "force": false }`（`force:true` で再読み取り）
- 認証: ログイン中ユーザーのJWT（`Authorization: Bearer <access_token>`）。`has_edit_perm('property')` が必要
- 出力:
```json
{
  "success": true,
  "cached": false,
  "is_lease_contract": true,
  "fields": {
    "management_company": "…", "mgmt_phone": "…", "mgmt_contact": null,
    "landlord_name": "…", "landlord_phone": null, "tenant_name": "…", "property_address": "…",
    "rent": 493196, "rent_tax_note": "税別", "common_fee": 30000,
    "area_sqm": 67.4, "tsubo": 20.38,
    "contract_type": "普通借家契約",
    "contract_date": "2021-10-01", "contract_start": "2021-10-01", "contract_end": "2025-09-30",
    "renewal_date": "2025-09-30", "auto_renewal": true, "renewal_fee": "賃料の1か月分", "notice_period": "6か月前",
    "deposit": "2,690,160円", "amortization": "賃料の1か月"
  },
  "evidence": { "rent": "第5条 賃料は月額金493,196円とする…", "renewal_date": "第3条 期間は…" },

```
- 値が契約書に無い項目は `null`（推測しない）。エラー時は `{ "error": "…" }` と HTTP 4xx/5xx。

## 2. 担当Fにお願いすること（`src/app/properties/` の画面）

| # | 内容 |
|---|---|
| 1 | 契約書をアップロード（既存の `uploadDocument`）した**直後に** `contract-extract` を呼ぶ。読み取り中は「📄 契約書を読み取り中…（10〜30秒）」を表示し、画面操作は妨げない |
| 2 | 結果を**フォームに自動入力**する。`fields` の対応: `management_company`→管理会社 / `mgmt_phone`→管理会社電話 / `mgmt_contact`→管理会社担当 / `rent`→賃料 / `tsubo`→坪数 / `contract_type`→契約種別 / `contract_date`→契約日 / `renewal_date`→更新日 / `deposit`→敷金 / `amortization`→償却 / `landlord_name`・`landlord_phone`→貸主 |
| 3 | **既に値が入っている欄は上書きしない**。「現在の値 → 読み取り値」を並べて、欄ごとに「読み取り値を使う」を選ばせる（空欄は自動で入れてよい） |
| 4 | 各項目の横に **根拠（`evidence`）** を表示（ホバー／「根拠を見る」）。`needs_review` と `warnings` は赤字の注意欄に一覧表示 |
| 5 | **「保存」は必ず人が押す**（AIの結果をそのまま保存しない）。保存後、更新日(`renewal_date`)があれば `info.deadlines` に「◯◯店 契約更新」で登録・更新（既存の期限連携と同じ仕組み。書類は `document_id` で紐付け） |
| 6 | 参考項目（`common_fee`・`renewal_fee`・`notice_period`・`auto_renewal`・`property_address`・`rent_tax_note`）は、フォームに欄が無いのでメモ欄へ「追記する」ボタンで追記できるようにする（勝手には書かない） |
| 7 | 「🔄 契約書を再読み取り」ボタン（`force:true`）。`is_lease_contract:false`（賃貸借契約書でない）の場合は「契約書ではなさそうです」と表示して自動入力しない |
| 8 | 既存の物件（契約書が `document_id` で紐付き済み）にも「契約書から読み取り」ボタンを置く（既存データとの差分確認用） |

## 3. 注意
- **契約書は機密**: 結果（金額・相手先）をコンソールやログに出さない。
- 賃料・日付は経理・期限に直結するため、**自動で本保存しない**（上の5）。
- 担当Cのデプロイ前に画面を作る場合は、上記のJSON例の固定値を返すモックで進めてよい。
