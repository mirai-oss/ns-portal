# 手順書: 従業員と Slack の紐づけ（招待・自動紐づけ）2026-11-08

## できあがりの姿
- 入社前は LINE、**入社後は Slack**（ユーザー方針）。Slack に登録した人は、管理システムの従業員情報と**自動で紐づき**ます。
- 紐づく条件は 1 つだけ: **管理システムに登録しているメール ＝ Slack に登録したメール**。
- 従業員一覧（nippo → 従業員管理）に「💬Slack」「Slack未連携」の目印が出て、「未連携・未提出だけ探す → 💬 Slack未連携のみ」で絞れます。
- 従業員の画面に「💬 Slack連携」の欄があり、LINE で招待を送る／招待の文面をコピー／Slack のメンバーから選んで手で紐づける／紐づけを外す、ができます。
- 紐づいた人は、担当店舗の勤怠確認（○×・修正・打刻削除）を Slack で押せるようになります。承認はマスターだけ。

### 4. 招待リンクを作って、管理システムに入れる（ユーザー作業・2 分）
1. Slack（PC）の左上のワークスペース名 →「**メンバーを招待**」→「**招待リンクをコピー**」。
   - 有効期限は長いものを選ぶ（プランによって「無期限」が選べます。短いと切れるたびに作り直し）。
2. nippo → 従業員管理 →「未連携・未提出だけ探す」→ **💬 Slack未連携のみ** にチェック → 出てきた「💬 Slack 連携」の箱の「招待リンク」欄に貼って **保存**。
   - 成功の見分け方: 「招待リンクを保存しました」と出て、欄の上にリンクが表示される。

## ② 店長など 1 人を Slack に入れるとき
1. nippo → 従業員管理 → その人を押す →「💬 Slack連携」→ **📱✉️ LINE とメールの両方に送る（初回向け）**（LINE をブロックしている人にも届くように、初回は両方）。2 回目以降は「📱 LINE だけ」「✉️ メールだけ」も使えます。
   - LINE 未連携の人は **✉️ メール（登録メール）で送る** を押す（管理システムに登録してあるメール宛に同じ文面が届きます。差出人は info@ns0314.com＝請求書メールの「メール作成」と同じ Gmail の仕組み）。
   - どちらも難しいときは **📋 招待の文面をコピー** して、好きな方法で渡してください。
   - 送られる文面（名前とメールはその人のもの）:
     > 【○○さん】会社の連絡を Slack に移します。下のリンクから Slack に登録してください。
     > （招待リンク）
     > ★登録するときのメールは、管理システムに登録している「xxx@example.com」にしてください（同じメールだと自動で管理システムと紐づきます）。
2. 本人が届いたリンクから Slack に登録する。**登録するメールは、案内に書いてある「管理システムのメール」**。
3. 登録した瞬間に自動で紐づき、本人の Slack に「管理システムと紐づきました」と届きます。一覧の目印が「💬Slack」に変わります。
4. 違うメールで登録してしまったとき: その人の画面 →「👤 Slack のメンバーから選んで紐づける」→ 名前を選んで「この人に紐づける」。

## ③ まとめて送るとき
「未連携・未提出だけ探す → 💬 Slack未連携のみ」で絞り、「○名へ一斉に招待を送る」。初めて送る人には LINE とメールの両方、2 回目以降は LINE 連携済みなら LINE、それ以外は登録メール宛に送られます。

## 仕組み（読まなくてよい）
- 表 `user_slack`（従業員 ↔ Slack ID・紐づけ方法 email/team_join/manual・Slack の表示名）／`slack_invite_log`（誰にいつ招待を送ったか）／`app_settings` の `slack_invite`（招待リンク）。
