# 手順書: 入社登録 Phase 2（交通費）・Phase 3（スマレジ管理画面の自動操作）・Phase 4 の土台（中止）

作成 2026-11-10。コードはリポジトリにありますが、**本番には入っていません**（SQL 未適用・EF 未デプロイ・Mac の実行フラグ OFF）。

## 0. 何ができるようになるか

- **交通費**: 入社フォームに「通勤について（通勤手段・経路・片道の交通費・バス利用・特記）」が任意で付きます。本部が親メッセージのスレッドで「🔁 再検索」を押すと、駅すぱあとで本人の最寄り駅→店舗の最寄り駅の経路候補を調べ、申請額と比べて「自動承認できます／本部の確認が必要／本人に確認が必要／検索できません」を出します。**最安というだけで否認はしません。承認は必ず人がボタンを押します。**
- 承認後、親メッセージの「🚌 交通費を設定」で 支給形態（勤務回数ごと／勤務日数ごと／月額）・適用開始日・適用事業所・金額・上限 を入れると、**Mac mini の自動操作（Playwright）がスマレジ管理画面に入力**し、保存後にスマレジから読み直して一致を確認します。
- 源泉所得税・個別 Web 給与明細・メールアドレスも同じ仕組み（ジョブ）で設定できます（画面の場所は立会い後に確定）。
- 「⛔ 中止」で入社手続きを止められます（理由 5 区分。スマレジの従業員は消しません）。採用管理に離脱段階・理由が別々に残ります。

## 2. ふだんの使い方（本部）

### 2-1. 交通費（スレッド）
1. 入社フォームに通勤情報が入っていれば、親メッセージの作成後に「🔁 再検索」を押します（Phase 2 後半で自動化）。
2. スレッドに「🚃 交通費の確認」が届きます。本人の申請額・検索の最安・経路の候補・判定が並びます。
3. 次のどれかを押します。
   - **✅ 申請額 ○○円で承認** … 本人の申請どおり。
   - **✅ 検索額 ○○円で承認** … 検索の最安で。
   - **🙋 本人に確認** … 差が大きいとき。本人に経路を聞いてから、もう一度「再検索」か「承認」。
   - **🔁 再検索** … 最寄り駅や店舗を直したあと。
4. 承認すると「交通費の経路確認」が ✅ になります。

### 2-2. 交通費をスマレジに入れる（親メッセージ「🚌 交通費を設定」）
1. 支給形態（勤務回数ごと／勤務日数ごと／月額）・適用開始日（初期値は入社日）・適用事業所（全部 or 1 店舗）・金額（勤務回数ごとは往復額が初期値）・上限（AL は 6,000 円が初期値）を入れて「登録してスマレジに反映」。
2. スレッドに「🚌 交通費の設定を登録しました … Mac の自動操作で反映します」→ 数分後に結果。
   - ✅ 設定しました＋「保存後に読み直して一致」→ 本部タスク「交通費」に自動 ✓。
   - ⏳ 失敗し、あとで再試行（最大 3 回。10 分→20 分→30 分後）。
   - 🙋 失敗（手動対応が必要）→ 本部タスクに「手動対応: 交通費をスマレジ管理画面で設定」の工程が足されます。管理画面で入れたらその工程を完了にしてください。「🔁 もう一度自動で試す」も押せます。

### 2-3. 中止（親メッセージ「⛔ 中止」）
理由を選んで「中止する」。未完了の項目と自動操作が止まり、採用管理に離脱段階・理由が記録されます。本部タスクは手で完了または削除してください。

## 3. 立会いで確認すること（スマレジ管理画面・30 分）

API リファレンスで分かっていること: 交通費は `transportationCostApply[]`（支給形態 0 勤務回数ごと／1 月額／2 勤務日数ごと・金額・上限・上限（事業所ごと）・適用開始日・事業所 ID）、源泉所得税は `withholdingIncomeTaxes[]`（区分 1 甲／2 乙・配偶者区分・扶養人数・適用開始月）、個別 Web 給与明細は `personalWebStatementScreenDisplayFlag`、メールは `mail`。**上限の単位（月額か 1 回か）は資料に無い**ので画面で確認します。

| # | 画面で見ること | 何に使うか |

## 4. うまくいかないとき

| 症状 | 見るところ・直し方 |
|---|---|
| 再検索で「キーが未設定」 | §1-1。評価版が来るまでは人が確認して承認 |
| 再検索で「店舗の最寄り駅が未設定」 | nippo → 店舗管理で最寄り駅を登録（エース 本厚木・じんべぇ 川崎／新横浜・秋葉原 肉寿司 が未設定） |
| 自動設定がずっと ⏳ | Mac mini の `.env` に `SMAREGI_UI_JOBS=1` があるか／`logs/dispatch.log` に「スマレジ UI ジョブ」が出ているか／朝 06:30〜07:30 は動かない |
| 🙋 認証切れ | Mac mini で `npm run login:ns` 相当の再ログイン（smaregi-payroll と同じプロファイル） |
| 🙋 画面が変わった（SCREEN_CHANGED） | スマレジの画面更新。`SEL` を直す（私に連絡） |
