GMOあおぞら 手動ログイン確認の手順書

作成 2026-11-28 ／ 所要 20〜30 分 ／ やるのは Mac mini の前で、1 回だけ
これは何のため？
GMOあおぞらは、ログインのあとに「追加の本人確認」が出るかどうかが、人が実際にログインしてみないと分かりません。これが分かると、「機械が自動で明細を取れるか」「どの方法なら規約にも合うか」が決まります。
この手順で使う道具は、IDもパスワードも入力しません・読みません・保存しません。ログインは、あなたが手で行います。画面の「どんなボタンがあるか」だけを記録します（口座番号のような長い数字は、記録するときに伏せ字になります）。
先に読んでください（守ること）
  • パスワードを間違えない：何回も間違えるとロックされます（GMOの規約にあります）。1 回で入れられるよう、落ち着いて。
  • 追加の認証（SMS・アプリ・証明書など）が出たら、それも手で進めてください。うまくいかなければ、そこで止めて構いません（どこで止まったかが、そのまま大事な情報です）。
  • ふだんの Chrome は使いません。この道具が専用のブラウザを別に開きます（今開いている Chrome には触りません）。
  • お金が動く操作（振込・承認）は絶対にしません。見るだけ・CSV をダウンロードするだけです。
  • 14:00〜14:30 の PayPay の自動取込の時間は避けてください（動作が重なるのを避けるため）。

やること（番号の順に、1 つずつ）

1ターミナルを開く

画面下の Dock（アイコンが並んでいる所）から「ターミナル」（黒い画面のアイコン）を押して開きます。
✅ うまくいった目印：黒（または白）の画面が出て、文字を打てる状態になる。

2道具のある場所へ移動する

次の 1 行をそのままコピーして、ターミナルに貼り付けて、Enter キーを押します。 
cd /Users/mirai/ns-daily-import-wt-bank
✅ うまくいった目印：エラーが出ず、次の行にまた入力待ちの印が出る。
（「No such file or directory」と出たら、ここで止めて、その文字をそのまま教えてください。）

3道具を起動する

次の 1 行をコピーして貼り付けて、Enter。 
node gmo-observe.js
✅ うまくいった目印：新しいブラウザの窓が 1 つ開き、GMOあおぞらのログイン画面が出る。ターミナルには「ブラウザでログインしてください」と出る。
ターミナルはこのまま閉じないでください。

4手でログインする

開いたブラウザの窓で、いつもどおり、IDとパスワードを手で入力してログインします。
もし「追加の確認」の画面が出たら（例：SMSの番号、スマホのアプリ、確認コード、証明書の選択）、それも手で進めます。
📝 メモしてください（紙でもスマホでも）：
  • 追加の確認は出たか／出なかったか
  • 出た場合、どんな方法か（SMS／アプリ／メール／証明書／その他）
  • それは毎回出る感じか、前にログインした端末だと出ない感じか（分かる範囲で）
✅ うまくいった目印：ログイン後のトップ画面（口座の残高や「入出金明細」などのメニュー）が見える。
この時点では、ターミナルには何も押さないでください。

5画面を 1 つずつ記録する（ここが本番）

次の画面へ移るたびに、ブラウザで画面を開いてから、ターミナルに戻って Enter キーを 1 回押します。「記録: …」と出れば記録できています。
  1. トップ画面を開いた状態で → ターミナルで Enter
  2. 「入出金明細」の画面を開いて → ターミナルで Enter
  3. 口座を切り替える所（口座名が出ている所、または「口座切替」）を押して、別の口座に切り替えて → ターミナルで Enter
    　 📝 切り替えの方法をメモ：画面上のプルダウンから？ 別画面に戻る？ ログインし直し？
  4. 「CSVダウンロード」の画面（明細をファイルで取る所）を開いて → ターミナルで Enter
✅ うまくいった目印：ターミナルに「記録: /…… 「画面の名前」 リンク○・ボタン○」のような行が 4 回出る。

6CSV を 1 つだけダウンロードする

CSV のダウンロード画面で、期間は「直近 1 週間」くらいの短いものを選んで、ダウンロードします。
✅ うまくいった目印：ターミナルに「⬇ ダウンロードを保存: …」と出る。
📝 メモ：期間をどこまで広げられたか（例：「最大 1 年」「最大 3 か月」と画面に出ていれば、その文言）。
（ダウンロードが出来なかったり、画面が違ったりしたら、そこまででも構いません。）

7終わらせる

  1. ブラウザの窓で、「ログアウト」を押します（押し忘れても、次の手順で閉じれば大丈夫です）。
  2. ターミナルに戻って、キーボードで q を打って Enter。
✅ うまくいった目印：ターミナルに「保存しました」のような行が出て、ブラウザの窓が閉じる。

  4. 途中で止まったら、どの番号で、画面に何と出たか（文字をそのまま）
IDとパスワードは、絶対に私に送らないでください。（道具の記録にも入りません。）
記録ファイルは、このMacの downloads/gmo-observe/ に保存されます（インターネットには出ません）。私が中身を読んで、「機械で自動取得できるか」「規約に合うか」を判断します。
この確認のあとも、自動ログインは動かしません。 GMOの自動取得は、規約・認証方式の確認が済んで、あなたが「本番で動かして良い」と承認するまで、本番では動きません。それまでは、CSV を手で取って取り込む方法（手動CSV取込）で運用します。
