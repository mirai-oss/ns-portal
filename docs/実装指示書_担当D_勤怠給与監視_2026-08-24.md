## D-1: 月またぎ再取込の修正（最優先・発見済みの実不具合）

- 現状: `smaregi-attendance-sync`は既定「昨日1日分」のみ。**当月1〜10日に前月分を再チェックする仕組みが無い**（旧CSV取込の`PREV_MONTH_UNTIL_DAY:10`が API移行時に引き継がれていない）
- 対応: `.github/workflows/smaregi-attendance-sync.yml`に「当日が1〜10日なら`date_from`=前月1日・`date_to`=前月末日の追加sync呼び出しを1回行う」ステップを追加（Edge Function自体は`date_from/date_to`対応済みなので変更不要が最短）
- `smaregi-payroll-reconcile`・`smaregi-attendance-anomaly-check`も同じ月またぎ影響を確認し必要なら同対応
- 検証: 前月日付を指定して手動実行→`labor_cost_daily`が正しく再取得・上書きされること（差分が出るなら妥当性を説明）

## D-2: 社員固定給の勤務日ベース按分（比較レポートまで）

- **確定済み仕様**: 按分=スマレジ勤怠実績（BQ）の従業員×店舗×月の労働時間シェア／日割り=**勤務日ベース**（その月の勤務日に労働時間比率で配分）／**打刻ゼロの月給者は暦日割りへ自動フォールバック**（産休・長期休暇対策）
- 実装: BQに按分ビュー作成→現行の手入力値（売上DB「社員人件費DB」シート由来・`fact_daily_store`の社員系列）との**比較レポートを週次で自動出力**（workflow新設・Larkまたはファイル）
- **切替はやらない**。ユーザーが比較レポートを承認したら、表示側の切替を担当Aへ引き継ぐ（WORKLOGに引き継ぎエントリ→Aの受領追記を待つ=Sync2）

## D-4: Anthropic API費用の自動レポート

- 取得: 公式Usage & Cost Admin API `GET https://api.anthropic.com/v1/organizations/cost_report?starting_at=...&ending_at=...&bucket_width=1d`（ヘッダー`x-api-key: <AdminAPIキー>`＋`anthropic-version: 2023-06-01`。金額はUSDセントの文字列・ページングは`has_more`/`next_page`）
- **円換算（確定仕様）**: 同じ日次バッチでその日のUSD/JPYレートを無料為替API（Frankfurter=ECB公表・キー不要）から取得し、**当日レートで換算した円額をレートごと保存**
- 保存: ハブSupabase新テーブル`api_cost_daily`（date／amount_cents／jpy_rate／amount_jpy／description等。日付入り新規SQLで追加）
- Lark配信: ①毎月1日「先月のAI利用料: ¥◯◯（$◯◯・平均レート◯◯）」②毎週月曜「今月の累計」③しきい値超過アラート（**金額はユーザーに確認**。例: 月$100）。D-3と同じWebhook
- **ユーザー作業（依頼して待つ）**: Anthropic ConsoleでAdmin APIキー発行（`sk-ant-admin01-`で始まる・通常キーと別物・**個人アカウント不可=Console→Settings→Organizationの組織設定が前提**・スコープは読み取り限定）→GitHub Secret登録。**手順書＋リンク付きで依頼すること**（ユーザーの過去フィードバック: リンク無しの手動作業依頼で詰まった実績あり）
- 表示側ウィジェットは担当F（F-1.5）。Dは`api_cost_daily`にデータを置くところまで
