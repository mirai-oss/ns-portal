## 2. スマレジ日給 API の送信形式（結果: 公式仕様で確認済み・実装を 1 点修正）

- 原文で確認した事項:

  - 日給（事業所未指定）の body は `{"division":1, "effectiveDate":"YYYY-MM-DD", "wage":整数}` ＝ **実装どおり**（月給と同形）。
  - 日給の effectiveDate は「1970-01-01以降、日給は月初日を指定してください」＝ **月初日が必須**（400「effectiveDate は日給・月給の場合は月初日を指定してください。」）。→ **修正**: `hr_save_wage`（SQL）・Slack モーダルの検証・`smaregi-sync` wage_update・nippo の賃金カード（自動で 1 日に補正）に月初日チェックを追加。モーダルの選択肢を「日給（適用開始日は月初日）」に。

  - POST 201 `{"staffId","wageApplyIds":[…]}`／PUT 200／400 detail の代表例は上記＋「同一適用開始日に重複する賃金設定が存在します。」
