# 設計メモ: 毎月来る請求書の自動仕訳（勘定科目・金額・店舗別部門・PL反映）— 順番と方法（2026-10-08）

作成: 2026-10-08 司令塔 ／ 状態: **ロードマップ提示・質問中（§5 Q1〜Q3）**。実装指示は回答後（担当C主担当・Phase1=担当Fの土台が前提）
ユーザー要望: 給与仕訳と同じく、毎月来る請求書も添付するだけで勘定科目・金額・店舗（部門）を自動で仕訳し、PLにも反映したい。請求書明細の店舗名が違うのでマッピングが必要。マッピングは自分で一旦やりたい。

## 0. 現状（司令塔実査・2026-10-08）
| 部品 | 今あるもの | 足りないもの |
|---|---|---|
| AI読み取り（`invoice-ocr`） | 請求元・請求番号・合計金額・支払期日・宛先法人（ヘッダーだけ） | **明細行（店舗名・品目・金額・税区分）を読んでいない**→店舗別の行が作れない |
| 仕訳辞書（`mf_journal_templates`） | 法人（tenant）×ラベル×行の型。給与ではSync8で「法人×区分の自動割当」へ | **取引先→既定パターンの紐付けが無い**（毎回人が選ぶ） |
| 取引先マスタ（`vendors`） | 会計用の取引先。請求元の表記ゆれ→取引先の解決は自前の正規化 | 請求元名の別名（`corporation_aliases`相当の取引先版）・既定パターン・明細店舗名の対応 |
| 店舗マッピング | 給与: `mf_department_name`＋`store_aliases`。**Sync9でPhase1=`store_external_mappings`＋`resolve_store()`（担当F・着手中）** | 請求書明細の店舗表記→店舗を`source_system='invoice'`＋取引先ヒントで解く（Phase1の表でそのまま可能） |
| 検算・自動OK・一括登録 | 給与仕訳Sync8 §6で実装中（検算OK→緑バッジ→まとめて登録） | 請求書用の検算式（明細合計＝請求合計±1円・税込/税別の整合） |
| PL反映 | `pl-fee-reflect` confirm（勘定科目×店舗×月をPLへ・取り消し可）。精算書連携も既存 | 自動OK時に「PL反映の下書き」まで同時に作る導線 |
| 定期請求マスタ（`ar_recurring_master`） | 売上入金側のみ稼働。請求書側（kind=invoice）は照合先が無く未対応 | 「毎月来るはずの請求書が来ていない」の検知（後回し可） |

**結論**: 給与で作っている「パターン＋AI読み取り＋店舗マッピング＋検算＋一括登録」の型を請求書に横展開すれば、**定期取引先の請求書は「添付するだけ」で仕訳の下書きまで自動化できる**。1社目は人が確認してパターン化、2回目以降は自動。

## 1. 到達点（完成形の流れ）
```
請求書を添付（メール/アップロード）
→ AIがヘッダー＋明細行を読む（請求元・合計・明細の店舗表記/品目/金額/税）
→ 請求元の表記ゆれ→取引先を特定（取引先別名）→ 宛先から法人を特定（corporation_aliases）
→ 取引先×法人の「既定の仕訳パターン」を自動適用（勘定科目・税区分・貸方=未払金 等）
→ 明細の店舗表記→ resolve_store('invoice', name, vendor_hint)→ 店舗→ MF部門 → 店舗別の借方行を自動生成
→ 検算（明細合計＝請求合計／税の整合／前月との差±30%）→ 自動OK=緑バッジ
→ 一覧で「チェックした請求書をまとめて登録」（1クリック・無人登録はしない）
→ 登録と同時にPL反映の下書き（既存plfee confirm）→ 人が承認
→ 店舗表記が未解決なら隔離（kd_unresolved_names）→「この店舗として登録」→ 次回から自動
```

## 3. マッピングを「自分でやる」方法（3通り・併用可）
- **A 一覧をチャットで送る**（最初の10社向け・おすすめ）: 司令塔が用意する表（取引先／請求元の表記／宛先法人／明細の店舗表記／正式店舗／勘定科目）を埋めて送る→担当Fのseed（Phase1）と担当Cの既定パターンに一括投入
- **B 管理画面で登録**（Phase1完了後）: ポータル設定→外部マッピング（source=invoice）・取引先の既定パターン
- **C その場で登録**（運用開始後）: 請求書詳細で未解決の店舗表記が出たら「この店舗として登録」。1回登録すれば次回から自動

## 4. 「添付するだけで整う」か（正直な答え）
- **定期の取引先（毎月同じ形式）**: ⑥完了後は**はい**。1回目だけ人が確認してパターン化、2回目以降は添付→自動OK→一括登録1クリック
- **初めての取引先・形式が毎回違う請求書**: 自動OKにならず「要確認」で止まる（AIに勝手に決めさせない）。人が確定すれば次回から自動
- **無人での登録**: しない（確定方針「AI=下書き・人=承認」）。一括登録1クリックまで
