# 手順書: AI開発コックピット セットアップ（2026-08-31）

対象: 中山さん（所要 約5分）。トークンの実値はこの文書には書かない（チャットで渡した「貼り付け用」ファイルにのみ記載）。

## 全体像

```
各PCのClaude Code → ai-cockpit CLI（ns-portal/tools/）→ Edge Function cockpit-ingest
  → Supabase ck_テーブル（RLS=マスター限定）→ cockpit.html（ポータル→管理→🛠️AI開発コックピット）
```

## ① SQL実行（1回だけ・どのPCからでも）

Supabase SQL Editor: https://supabase.com/dashboard/project/uuvsxzhpxtghojoubjcc/sql/new

1. `supabase/2026-08-31_cockpit.sql`（テーブル・RLS・端末登録）を貼り付けて Run
2. `supabase/2026-08-31_cockpit_seed.sql`（今のタスクの初期投入）を貼り付けて Run
3. トークン登録SQL（チャットで渡した貼り付け用ファイル内・4行）を貼り付けて Run

いずれも冪等（2回実行しても安全）。

## ② 各PCのトークン設定（PC1台につき1回）

`~/.ns-cockpit/config` に INGEST_URL / TOKEN / DEVICE_KEY の3行を書く（コマンドは貼り付け用ファイル参照）。
- MacBook = `DEVICE_KEY=macbook`（2026-08-31 Claude設定済み）
- Mac mini = `DEVICE_KEY=mac-mini`
- 新しいPCを増やすときも同じ3行（DEVICE_KEYだけ変える。ck_devicesへは初回送信時に自動登録）

## ③ 動作確認

- ポータル → 管理 → 🛠️AI開発コックピット を2台で開き、同じ内容が見えること
- マスター以外のアカウントではメニューに出ない・URL直打ちでも「マスター専用」で止まること
- ターミナルで `~/ns-portal/tools/ai-cockpit note --agent 司令塔 --message "接続テスト"` → 画面の「実行・変更履歴」に出ること

## トークンを変えたくなったら

新しい値で①-3のSQLを再実行 → 各PCの `~/.ns-cockpit/config` のTOKEN行を書き換え。

## Edge Functionの再デプロイ（開発者向けメモ）

```bash
supabase functions deploy cockpit-ingest --no-verify-jwt --project-ref uuvsxzhpxtghojoubjcc
```
cockpit-* は担当H専任（鉄則#4）。独自トークン認証のため `--no-verify-jwt` が必須。
