手順書：精算ダッシュボードを更新する（v5.25）

目的：変動ロイヤリティを、レジ実績の売上から計算する変更を、精算ダッシュボードに入れます（2026年9月分から）。所要時間は10分ほどです。

先にお伝えしておくこと：
・これはGoogleのスプレッドシートの中にあるプログラム（Apps Script）を、新しいものに入れ替える作業です。
・入れ替えたあと、必ず「バージョンを新しくして」デプロイします（手順4）。「新しいデプロイ」を選ぶと、アドレスが変わってしまい、画面が動かなくなります。

まず：どちらの方法でやるか

  • 方法A（おすすめ・簡単）：添付の SeisanDashboard_v5.25_paste.txt の中身を、全部コピーして、貼り替える。
  • 方法B（Aのファイルが開けないとき）：この手順書の一番下（付録）にある、10か所の小さな書き換えを、1つずつ行う。

方法A：全部貼り替える

  1. ファイルの中身をコピーする
    添付の SeisanDashboard_v5.25_paste.txt を、Macの「テキストエディット」で開きます（ファイルを右クリック →「このアプリケーションで開く」→「テキストエディット」）。
    開いたら、⌘+A（全部選択）→ ⌘+C（コピー）。（大きなファイルなので、開くのに数秒かかります。もし、どうしても開けないときは、方法Bにしてください。）
  2. 精算ダッシュボードのスプレッドシートを開く
    いつも、精算のデータを入れている、Googleスプレッドシートです。開いたら、上のメニューの 「拡張機能」→「Apps Script」 を押します。新しいタブでプログラムの画面が開きます。
  3. 古いプログラムを、新しいものに入れ替える
    左の「ファイル」の一覧に、SeisanDashboard（または SeisanDashboard.gs）があります。これをクリックします。
    右の大きな文字の場所をクリックして、⌘+A（全部選択）→ ⌘+V（さっきコピーしたものを貼り付け）。
    上の「💾 保存」（またはその右の保存アイコン）を押します。
    ⚠️ SeisanDashboard 以外のファイルが、一覧にあっても、触らないでください。
  4. デプロイする（ここが大事）
    右上の青い 「デプロイ」 → 「デプロイを管理」 を押します。
    今あるデプロイ（「ウェブアプリ」）の右の ✏️（えんぴつ） を押します。
    「バージョン」の欄を押して、「新バージョン」を選びます。
    「デプロイ」を押して、完了です。
    ⚠️「新しいデプロイ」は選ばないでください（アドレスが変わります）。必ず「デプロイを管理」→ ✏️ → 「新バージョン」です。
  5. うまくいったか、確認する
    次のアドレスを、ブラウザで開きます：
    https://script.google.com/macros/s/AKfycbzwYN9uSEtcJHSKSVQCoQOrllhO7G6gR-E4dvP-V4o_VdGXr9VQx2mbYYPNyNEFSQCiKg/exec?action=ping
    画面に "ver":"v5.25-roy-actual" と出れば、成功です。
    （古いままの場合は v5.24-removeextline と出ます。その場合は、手順4をやり直してください。）
これで完了です。完了したら、私（担当C）に「GAS更新した」と伝えてください。9月分の精算書の確認に進みます。

うまくいかないとき

  • 権限の確認画面が出たとき：「許可を確認」→ 自分のアカウントを選び →「詳細」→「（安全ではないページ）に移動」→「許可」。
  • 保存のときに赤いエラーが出たとき：貼り付けの途中で切れている可能性があります。もう一度、⌘+A → ⌘+V でやり直してください。
  • ?action=ping を開いても、何も出ないとき：デプロイが終わっていません。手順4をもう一度やってください。
  • 元に戻したいとき：「デプロイ」→「デプロイを管理」→ ✏️ →「バージョン」から、前のバージョンを選んで、デプロイします。

付録：方法B（小さな書き換えを10か所）

Apps Scriptの画面で、⌘+F（検索）を使って、書き換える場所を探します。「置換」は、検索窓の左の「▸」を押すと出ます（または ⌘+⇧+H）。
書き換えが終わったら、方法Aの手順4（デプロイ）と5（確認）を行ってください。

  1. 【追加】 次の1行を探します：
    var SD_START_MONTH = '2026-03';
    そのすぐ下に、次を追加します：
    // 2026-10-15: この月以降は、変動ロイヤリティを「精算書の売上合計」ではなく「売上シート（分析_日別店舗 S列 支払合計＝レジ実績）の月間売上」から計算する。
// 売上シートは、毎月3日の月次照合（ns-daily-import cash-sales-monthly-check）でレジ(POS)と照合され、ずれていればレジの値に修正される。
// 過去の月は従来どおり（精算書の売上合計×率）。売上シートの値が取れない店舗・月も従来の計算にフォールバックする。
var SD_ROYALTY_ACTUAL_FROM = '2026-09';
var SD_ACTUAL_MEMO_ = {}; // 実行中のメモ: 対象月 → {店舗名(正規化): 月間売上} または null
  2. 【置き換え】 次の1行を探します：
    function sd_settle_(rows, monthKey, rateStr, fixed) {
    これを、次の内容に置き換えます（前に、新しい関数が加わります）：
    /* 変動ロイヤリティの基準にする「売上シート（レジ実績）の月間売上」。取れない・対象月より前なら null（従来の計算へ） */
function sd_actualSalesFor_(salesName, monthKey) {
  try {
    if (!salesName || String(monthKey) < SD_ROYALTY_ACTUAL_FROM) return null;
    var map = SD_ACTUAL_MEMO_[monthKey];

      map = sd_paySumsCached_(sd_extConfig_(), monthKey, cfg0) || null;
      SD_ACTUAL_MEMO_[monthKey] = map;
    }
    if (!map) return null;
    var v = map[sd_norm_(salesName)];
    return (v != null && Number(v) > 0) ? Number(v) : null;
  } catch (e) { return null; }
}

  3. 【置き換え】 次の1行を探します：
    var royV = Math.round(sales * rate);
    これを、次の3行に置き換えます：
      var actualSales = sd_actualSalesFor_(salesName, monthKey);
  var royBase = actualSales != null ? actualSales : sales; // 2026-09分以降: レジ実績（売上シート）の月間売上。取れなければ精算書の売上合計
  var royV = Math.round(royBase * rate);
  4. 【置き換え】 次の1行を探します：
