# 手順書: Google口コミ直結化で、あなたにやってもらう4つのこと（2026-11-06）

全部で 15〜20 分くらいです。順番どおりにやってください。
途中で分からなくなったら、画面の見えているものをそのまま教えてください。

**用意するもの**
- このパソコン（Mac mini）と、いつも使っているターミナル（黒い画面）
- Google にログインしているブラウザ（Chrome）

**用語の説明**
- 「APIキー」＝ Google に「うちの会社です」と名乗るための長い暗号の文字列。他の人に見せない。
- 「Supabase（スパベース）」＝ うちのデータの倉庫。ここに口コミの数をためる。
- 「ターミナルで実行」＝ 黒い画面にコマンドを貼り付けて Enter を押すこと。

---

## 手順1: APIキーをコピーして、Supabase の金庫に入れる（5分）

### 1-1. APIキーを見つける
1. Chrome で、スプレッドシート「**売上DB**」を開く。
2. 上のメニューの「**拡張機能**」→「**Apps Script**」をクリック。新しいタブが開く。
3. 左側に並んでいるアイコンの中の **歯車（⚙ プロジェクトの設定）** をクリック。
4. 画面を一番下までスクロールすると「**スクリプト プロパティ**」という表がある。
5. 表の中に「**PLACES_API_KEY**」という行がある。その右側の「値」の文字列（`AIza` で始まる長い文字）を全部選んでコピー（⌘+C）。

> うまくいっている合図: コピーした文字は `AIza` で始まり、30〜40文字くらいある。

### 1-2. コピーした文字をファイルに保存する
1. ターミナルを開く。
2. 下の枠の文を貼り付ける。**ただし貼る前に**、`ここに貼る` の部分を、さっきコピーした文字に置きかえる（`ここに貼る` を消して ⌘+V）。それから Enter。

```bash
printf 'GOOGLE_PLACES_API_KEY=ここに貼る\n' > ~/.config/ns-portal/google_places.env && chmod 600 ~/.config/ns-portal/google_places.env
```

> うまくいっている合図: 何も表示されずに、次の行に `%` や `$` が出る（静かなのが正解）。
> 困ったときの合図: `No such file` と出たら、そのまま私に教えてください。

### 1-3. Supabase の金庫に入れる
下の枠をそのまま貼り付けて Enter。

```bash
npx supabase secrets set --env-file ~/.config/ns-portal/google_places.env --project-ref uuvsxzhpxtghojoubjcc
```

- 途中で `Ok to proceed? (y)` と聞かれたら、キーボードで **y** を押して Enter。

> うまくいっている合図: `Finished supabase secrets set.` と出る。
> 困ったときの合図: `Access token not provided` や `unauthorized` と出たら、そのまま私に教えてください（ログインが切れているだけです）。

## 手順2: Google 側で、キーが「口コミ専用」になっているか見る（3分）

これは**見るだけ**です。変更は、必要なときだけ。

1. Chrome で https://console.cloud.google.com/apis/credentials を開く。
2. 画面の上のほうにプロジェクト名が出ている。口コミ取得に使っているプロジェクトになっているか確認（違うときはクリックして選ぶ。分からなければ、見えている名前を私に教えてください）。
3. 「**API キー**」という表の中から、さっきの `AIza…` と同じキーの名前をクリック。
4. 右側（または下側）の「**API の制限**」という項目を見る。
   - 「**キーを制限**」が選ばれていて、一覧に「**Places API (New)**」だけ入っていれば OK。
   - 「**キーを制限しない**」になっていたら、「キーを制限」を選び、一覧から「Places API (New)」にチェックを入れて、一番下の「**保存**」を押す。
5. 「OKだった」か「変更した」か「よく分からない画面だった」のどれかを私に教えてください。

> 注意: 「アプリケーションの制限」という別の項目は**触らない**でください（「なし」のままでOK）。

## 手順3: Supabase に新しい表を作る（2分）

ターミナルで、下の2つを**上から順に**貼り付けて Enter。

まず作業フォルダに移動:
```bash
cd ~/Claude/ns-portal
```

次に表を作る:
```bash
python3 scripts/apply_sql.py supabase/2026-11-06_google_reviews_direct.sql
```

> うまくいっている合図: 1行目に `適用OK:` と出る。
> 困ったときの合図: `エラー HTTP` と出たら、その下に出た文を全部コピーして私に送ってください。

## 手順4: 取得プログラムを Supabase に置く（3分）

同じターミナルで、下の枠を貼り付けて Enter。

```bash
npx supabase functions deploy google-reviews-fetch --project-ref uuvsxzhpxtghojoubjcc --no-verify-jwt --yes
```

- 途中で `Ok to proceed? (y)` と聞かれたら **y** を押して Enter。
- 1〜2分、文字が流れます。待ってください。

> うまくいっている合図: 最後のほうに `Deployed Functions on project uuvsxzhpxtghojoubjcc: google-reviews-fetch` と出る。
> 困ったときの合図: `error` という赤い文字で止まったら、その行をコピーして私に送ってください。
