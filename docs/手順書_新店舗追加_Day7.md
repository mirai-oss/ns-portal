# 新店舗追加手順書（3手順版）

作成: 2026-08-23／データ基盤統合ロードマップ Day7 成果物
対象読者: 非エンジニアでも実施できるように書いています。手順3まで終われば新店舗が全システムに反映されます。

---

## 一言で言うと

**自社側のシステムは「nippoの店舗管理画面」1箇所で完結します。** 外部サービス（スマレジ・Dinii等の外部の会社のシステム）だけは、その会社のサイトで個別に登録が必要です（これはうちのシステムでは1箇所化できません）。

---

## 手順1: nippoの店舗管理画面で登録する

1. nippoに社長・本部権限でログイン
2. 「🏪 店舗管理」を開く
3. 「新しい店舗を追加」から店舗名を入力（店番号は自動採番されます）
4. 各項目を設定:
   - **法人**: 既存の法人から選ぶ（無ければ先に法人を登録）
   - **看板**: お店の実際の看板名（同じ建物に複数ブランドがある場合は複数入力）
   - **別名**: 口コミサイト（Googleマップ等）での表記が正式名と違う場合、そのまま追加（例:「個室×焼き鳥 博多焼き鳥食べ放題 鶏武者 新横浜店」）
   - **天気地点**: 横浜・本厚木・東京の3ボタンから近いものを選ぶ、または緯度経度を手入力
   - **配信グループ所属**: 日報・週報・月報をLarkまたはChatworkのどのグループに送るか、チェックを入れる
5. 「保存」

**これだけで自動的に反映される先**: 日報アプリ全般（シフト・チェックシート・応募者管理等）／ポータル／経営ダッシュボード（Supabaseから直読みしているため）／Lark・Chatworkの自動配信（配信グループの設定から自動生成されるため、コード修正不要）

## 手順2: 外部サービス側の登録（自社システムでは1箇所化できない部分）

これは店舗管理画面とは別に、各サービスのサイトで個別に行う必要があります。

| サービス | やること | 備考 |
|---|---|---|
| **スマレジ**（POSレジ） | スマレジの管理画面で新店舗を作成 | 作成後、手順1の店舗管理画面に戻って「スマレジ店舗と紐付け」のプルダウンから選択する |
| **Dinii**（オーダーシステム。導入する場合のみ） | Dinii側で新店舗を設定 | 加えて `ns-daily-import/config.js` の `NS_PAYMENT_STORE_NAMES`・`NS_MEDIA_STORE_NAMES`・`NSTYLE_STORES` のいずれか該当する配列に店舗名を追記してpushする（自動取込の対象に入れるため。エンジニア作業） |
| **ZeroRegi**（秋葉原 肉寿司専用のレジ。他店舗では使っていない） | 該当する場合のみ、同様に登録 | `config.js` の `ZEROREGI_STORE` を確認 |
| **入金口座（PayPay銀行等）** | 銀行側で新しい口座・入金情報を用意 | 実際の入金明細の店舗名表記が正式名と違う場合、手順1の「別名」に追加して吸収する |
| **売上を計上するスプレッドシート「分析_日別店舗」** | 通常は自動反映（店舗管理画面の別名から解決されるため） | もし店舗名が一致せず売上が計上されない場合のみ、手順1の「別名」を見直す |

## 手順3: 店舗管理画面の「未完了警告チェックリスト」で確認する

1. nippoの「🏪 店舗管理」画面を開き直す
2. 画面上部に「⚠️ 設定が未完了の営業中店舗」という警告が出ていないか確認する
3. 警告に出ている項目（スマレジ紐付け・法人・看板・別名のいずれか）があれば、手順1に戻って補完する
4. **警告が完全に消えたら完了**
