# ブランド（看板・屋号）の正本宣言

作成: 2026-08-21（データ基盤ロードマップ Day 2）

## 結論

**`public.stores.signs`列（jsonb配列）を、ブランド・看板名の唯一の正本とする。**

## 経緯

データ基盤監査（2026-08-21）で、ブランド情報が以下の3箇所に分散し、どれが正本か不明という指摘があった:

1. `public.stores.signs` — 店舗マスタの列。**12店舗すべてに実データが入っている**（例: 鳥一代本店→`["鳥一代"]`、鶏武者新横浜→`["鶏武者","匠味"]`、黒霧屋新横浜→`["黒霧屋","うお蔵","彩"]`）
2. `info.brands` — 社内情報管理システムのテーブル。**1行のみ**（「鳥一代」だけ）で、コード上の参照元も無し。過去の試作・未完成のまま放置されたテーブルと判断
3. 経営ダッシュボードのシート `DB_店舗親子` — スプレッドシート上の対応表

## 調査結果

- `info.brands`を読み書きするコードは`ns-info-system`・`ns-portal`のいずれにも存在しない（`grep`で確認、ヒットなし）→ 実質未使用
- `stores.signs`は12店舗全件が埋まっており、店舗管理の実運用で使われている列

## 決定

- 今後、ブランド・看板名を参照するコードは**必ず`stores.signs`を読む**
- `info.brands`は**削除しない**（他に依存が無いことは確認済みだが、テーブル削除は別途ユーザー確認の上で実施する方針。今回は宣言のみ）
- `DB_店舗親子`シートは今後`stores.signs`へ寄せていく（ロードマップDay 6「店舗マスタの派生25箇所」の対応範囲）
