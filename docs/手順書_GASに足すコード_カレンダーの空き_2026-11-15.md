# GAS に足すコード: 面接カレンダーの「空き」を調べる入口

作成 2026-11-13（下書き）。**まだ貼らないでください。** 承認が出てから、下の手順で進めます。

## これは何か

- 面接を確定する前に、「その時間、面接用の Google カレンダーに、別の予定が入っていないか」を調べるためのものです。
- いまの GAS（面接の Meet を発行しているもの）には、この調べる入口がありません。いまあるのは、「予定を作る・直す（meet）」と「予定を消す（delete_event）」の 2 つだけです（管理システムの画面が、この 2 つだけを呼んでいることから分かりました。GAS の中身そのものは、こちらでは見られていません）。
- 予定の変更と削除は、いまの入口のままで出来ます。**足すのは「空きを調べる」だけ**です。
- これを貼っても、管理システムの設定（`calendar_busy_check`）を true にするまでは、どこからも呼ばれません。

## 貼り付けるコード（そのまま全部コピーします）

```javascript
// ▼▼ ここから: 面接カレンダーの空きを調べる（2026-12 追加）▼▼
// 受け取るもの: p.calendar_id（カレンダーの番号）・p.start（始まりの日時）・p.minutes（長さ・分）・p.exclude_event_id（数えない予定の番号。無ければ空）
// 返すもの: { ok: true, busy: true か false }（busy が true ＝ その時間に、別の予定がある）
function nsBusy_(p) {
  var cal = (p.calendar_id && p.calendar_id !== 'primary') ? CalendarApp.getCalendarById(p.calendar_id) : CalendarApp.getDefaultCalendar();
  if (!cal) return nsBusyJson_({ ok: false, error: 'カレンダーが見つかりません' });
  var start = new Date(p.start);
  if (isNaN(start.getTime())) return nsBusyJson_({ ok: false, error: '日時が読めません' });
  var end = new Date(start.getTime() + (Number(p.minutes) || 30) * 60000);
  var skip = String(p.exclude_event_id || '').replace('@google.com', '');
  var events = cal.getEvents(start, end);
  var busy = false;
  for (var i = 0; i < events.length; i++) {
    if (events[i].isAllDayEvent()) continue;                       // 終日の予定は、数えない
    var id = String(events[i].getId() || '').replace('@google.com', '');
    if (skip && id === skip) continue;                             // いまの面接の予定そのものは、数えない
    busy = true;
    break;
  }
  return nsBusyJson_({ ok: true, busy: busy });
}
function nsBusyJson_(o) {
  return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON);
}
// ▲▲ ここまで ▲▲
```

## 手順（1 つずつ進めます）

1. パソコンで、面接の Meet を発行している **GAS のプロジェクト**を開きます（管理システムの「設定 → 📅 面接Meetの自動発行」に登録してある URL のプロジェクトです）。
   - うまくいくと: 左に「コード.gs」などのファイルの名前、右にプログラムの文字が見えます。
2. プログラムのいちばん下（最後の行のあと）をクリックして、上の「貼り付けるコード」を**全部**貼ります。
   - うまくいくと: いちばん下に `// ▲▲ ここまで ▲▲` の行が見えます。
3. プログラムの中から、`delete_event` という文字を探します（キーボードの「Ctrl」と「F」を同時に押すと、探す窓が出ます。Mac は「command」と「F」）。
   - うまくいくと: `delete_event` と書かれた行が 1 つ見つかります。
   - **見つからないとき・2 つ以上あるときは、ここで止めて、知らせてください。**（中身に合わせて、貼る場所を決め直します）
4. 見つかった行の**すぐ上**に、次の 1 行を貼ります。

   ```javascript
   if (p.action === 'busy') return nsBusy_(p);
   ```

   - 注意: この行の `p` は、「受け取った中身を入れている名前」です。見つかった行で、`p.action` ではなく、たとえば `data.action` や `body.action` と書かれていたら、貼った行と、手順 2 で貼ったコードの呼び出し（`nsBusy_(p)`）の `p` を、その名前に直します。**分からないときは、止めて知らせてください。**
   - この行は、合言葉（key）を確かめている行より**下**に入るようにします（`delete_event` の行のすぐ上なら、そうなっているはずです）。
5. 上の「💾（保存）」のボタンを押します。
   - うまくいくと: ファイルの名前の横の「●」の印が消えます。
6. 右上の「デプロイ」→「デプロイを管理」→ 鉛筆の印（編集）→「バージョン」を「新バージョン」にして →「デプロイ」を押します。
   - うまくいくと: 「デプロイを更新しました」と出ます。**ウェブアプリの URL は、今までと同じまま**です（URL が変わっていたら、止めて知らせてください）。
7. 終わったら、「貼りました」と知らせてください。こちらで、テスト用の応募者を使って、空いている時間と、予定のある時間の両方で確かめます。確かめが済んでから、設定（`calendar_busy_check`）を true にします。

## 元に戻すとき

- 手順 4 で貼った 1 行を消して、保存 → 手順 6 と同じようにデプロイします（手順 2 で貼ったコードは、残っていても動きに影響しません）。
