# かんたん手順書 請求書メールを取り込む「GAS」の一部を書きかえる — 2026-11-06

**やること:** 小さな「文章」を1か所だけ、新しいものに入れかえます。
**時間:** 5分くらい。**消えたり壊れたりするものはありません**（失敗しても、元の文章に戻せます）。

> **なんのため？**
> ガーデンから届く請求書のメール（URLが書いてあるメール）が、今は自動で取りこまれていません。
> 取りこむための「ルール」を直すと、自動で請求書が承認のところに来るようになります。

---

## 0. はじめる前に
- ブラウザ（Chrome など）を開きます。
- **shunji.nakayama@ns0314.com** のアカウントでログインしておきます。
  （右上の丸いマークを押すと、いまのアカウントが見えます。ちがうときは、切りかえてください）

## 1. 書きかえる場所を開く
1. 下の文字をコピーして、いちばん上の細長い四角（アドレス欄）に貼って、`Enter` を押します。

   `https://script.google.com/home`

2. 「マイプロジェクト」の一覧が出ます。その中から **「invoice-intake」** と書いてあるものを押します。
   - 見つからないときは、画面の上の検索の四角に `invoice-intake` と入れてさがします。
3. 黒っぽい（または白い）文字がたくさん書いてある画面が出ます。これが「スクリプトエディタ」です。

## 2. 「Code.gs」を開く
- 画面の左がわに、ファイルの名前が並んでいます。**`Code.gs`** を押します。

## 3. 書きかえる場所をさがす
1. 文字がたくさん書いてある四角の中を、1回クリックします。
2. キーボードで `Command` を押しながら `F` を押します。さがすための小さい四角が出ます。
3. その四角に、次の文字を入れます。

   `const SEARCH_QUERY`

4. `Enter` を押すと、その場所にジャンプします。次のような **3行** が見つかります。

```
const SEARCH_QUERY = '(' + ALIASES.map(function (a) { return 'to:' + a + ' OR cc:' + a; }).join(' OR ')
  + ' OR label:' + SOURCE_LABEL_NAME + ') -to:shunji.nakayama@ns0314.com -label:' + PROCESSED_LABEL_NAME;
```

（実際は2行か3行です。`const SEARCH_QUERY` から、`PROCESSED_LABEL_NAME;` の **`;`（セミコロン）まで** が、ひとかたまりです）

## 4. 書きかえる
1. `const SEARCH_QUERY` の **いちばん左** から、`PROCESSED_LABEL_NAME;` の **いちばん右** まで、マウスでなぞって選びます。
   （選んだところの色が変わります。**この前後の行は選ばないでください**）
2. キーボードで `Delete` を押して、消します。
3. 下の「新しい文章（ここから）」から「（ここまで）」までを、**ぜんぶ** コピーします。
4. さっき消した場所に、`Command + V` で貼ります。

### 新しい文章（ここから）
```javascript
const ALWAYS_FROM = ["k-mac.jp"];
const SEARCH_QUERY = '(((' + ALIASES.map(function (a) { return 'to:' + a + ' OR cc:' + a; }).join(' OR ')
  + ' OR label:' + SOURCE_LABEL_NAME + ') -to:shunji.nakayama@ns0314.com)'
  + ALWAYS_FROM.map(function (f) { return ' OR from:' + f; }).join('')
  + ') -label:' + PROCESSED_LABEL_NAME;
```

## 5. 保存する
- キーボードで `Command + S` を押します。
- 画面の上に「保存しました」のような文字が出れば成功です。
  （ずっと「保存中」のままのときは、画面の上の **ディスクのマーク（保存）** を押します）

**これで終わりです。** 新しいデプロイ（公開しなおし）は、しなくて大丈夫です。

## 6. 終わったら
1. Claude に **「貼りました」** と一言伝えてください。
2. 5分くらいすると、自動でメールが取りこまれます。Claude が、請求書が承認のところに来たかを確認します。

## うまくいかないとき
| こまったこと | こうする |
|---|---|
| `invoice-intake` が見つからない | 右上のアカウントが **shunji.nakayama@ns0314.com** か、もう一度たしかめます |
| `const SEARCH_QUERY` が見つからない | `Command + F` の四角に、スペースを入れずに入れなおします。それでもだめなら、`SEARCH_QUERY` だけで探します |
| 保存したら、赤い文字でエラーが出た | 貼った文章に、ぬけている文字がないか見ます。**元に戻したいとき:** `Command + Z` を何回か押します。そのあと、Claude に画面の文字を送ってください |
| ほかの行まで消えてしまった | `Command + Z` で元に戻して、もう一度「4」の1からやりなおします |

## 安心してください
- 書きかえるのは、「どのメールを取りこむか」を決める **1か所だけ** です。
- メールが消えたり、送られたりすることはありません。
- 変えたあとも、これまでと同じメールは、これまでと同じように取りこまれます。ふえるのは、**k-mac.jp から来たメール** だけです。
