# 手順書: A-6「予約」タブを本番へ反映する

対象: 担当A（経営ダッシュボード）が実装した「予約」タブのコード（`tori-dashboard/gas/Code.gs`・`tori-dashboard/app.js`）を、実際のダッシュボードで動くようにする作業。**AIはログイン情報・秘密鍵を扱えないため、この4ステップはユーザー作業**。

前提: 実装自体は完了済み（ローカルで動作確認済み・コミット前）。詳細はWORKLOG「A-6 経営ダッシュボード『予約』タブ Phase1実装」参照。

---

## ステップ①: Supabaseの接続情報をApps Scriptに登録する

**目的**: 新しい機能（`bqSyncReservation`）が、予約データの置き場所（Supabase）から値を取ってこられるようにする。

1. [Apps Scriptエディタを開く](https://script.google.com/home/projects/1s8wY21hbVrWSazUfXzZWzDU1dmtX7hFpsE6yRl4u2wT2pR_tH1QzagNn/edit)
2. 左メニューの歯車アイコン「プロジェクトの設定」を開く
3. 一番下「スクリプト プロパティ」→「スクリプト プロパティを追加」
4. 1つ目を追加: `SUPABASE_URL` = `https://uuvsxzhpxtghojoubjcc.supabase.co`（これは秘密情報ではなくそのまま使える）
5. 2つ目を追加: `SUPABASE_SERVICE_KEY` = （下記で取得した値を貼り付け）
6. 「スクリプト プロパティを保存」

**`SUPABASE_SERVICE_KEY`の値はここで取得**: [Supabaseダッシュボード → Settings → API](https://supabase.com/dashboard/project/uuvsxzhpxtghojoubjcc/settings/api) を開き、「Project API keys」の中の **service_role**（secretと表示されている方。anon/publishableではない）をコピーする。

（`ns-daily-import`の`.env`にも同じ値が入っているが、そちらはMac mini実機の中にしかない。Supabaseダッシュボードから直接取る方が早い）

## ステップ②: コードを本番へ反映する（デプロイ）

**目的**: 今回書いたコードを、実際に動いているダッシュボードに反映する。

1. このMacBookで更新済みファイルを開く（ターミナルで下記を実行するとテキストエディタで開く）
   ```bash
   open -a TextEdit ~/tori-dashboard/gas/Code.gs
   ```
2. 開いたら全選択してコピー（`Cmd+A` → `Cmd+C`）
3. [Apps Scriptエディタ](https://script.google.com/home/projects/1s8wY21hbVrWSazUfXzZWzDU1dmtX7hFpsE6yRl4u2wT2pR_tH1QzagNn/edit)の左側ファイル一覧から **「連携本番.gs」** を開く（これが`Code.gs`の本番側の名前）
4. 中身を全選択して削除（`Cmd+A` → `Delete`）
5. 手順2でコピーした内容を貼り付け（`Cmd+V`）
6. 保存（`Cmd+S`）
7. 上部メニュー「デプロイ」→「デプロイを管理」
8. 既存のデプロイの鉛筆（編集）アイコンをクリック
9. 「バージョン」のプルダウンを「新バージョン」に変更
10. 「デプロイ」ボタンを押す
11. 初回のみ、権限の再確認ダイアログが出ることがある（BigQueryへのアクセス許可）→ 許可する

**⚠️ 注意**: `appsscript.json`（別ファイル）は触らない。BigQuery連携の設定が消えると全機能が止まる。

## ステップ④: 予約データを初めてBigQueryへ取り込む

**目的**: Supabaseに溜まっている予約データ（4,650件）を、ダッシュボードが読めるBigQueryへ1回コピーする。

ステップ①の`SUPABASE_PROPERTIES`保存画面と同じ「スクリプト プロパティ」の一覧に、既存の `BQ_LOAD_TOKEN` という項目がすでにある（他の機能でも使っている値）。その値をコピーして、下のリンクの `【ここに貼り付け】` の部分を置き換えてブラウザで開く:

```
https://script.google.com/macros/s/AKfycbz9rd37EZa6X8WRMVEBrXobN8DbYWkHRlhFNYU5rd1UZ0V8j0-6shMQjEeoi4HDWZ0B/exec?action=bqSyncReservation&token=【ここに貼り付け】
```

`{"ok":true,"table":"stg_reservation","rows":4650}`のように件数が返れば成功（件数はその時点のSupabaseの件数に応じて変わる）。

このあと、ダッシュボードにログインして「予約」タブを開けば、実データが表示される。
