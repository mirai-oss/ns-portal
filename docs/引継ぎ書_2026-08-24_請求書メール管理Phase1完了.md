## 2. できること（実運用で追加された分含む）

- info@宛メール（To/CC）を5分おきに自動取込（＋「請求書」ラベル付きメールも追加ルートで拾う）
- 一覧（未処理/処理中/完了/対象外/すべて）・詳細（本文・添付・開封履歴・処理履歴）
- 処理ロック（DBレベルで二重処理防止・同時に2人が押しても1人しか成功しない）・完了・**完了の取消（未処理に戻す）**
- 添付は署名URLで閲覧。ダウンロードリンク式の請求書（パスワード解凍が必要なもの等）は**手動アップロードでメールに紐付け**られる
- 請求書情報（請求元・番号・金額・期限・状態＝下書き/確認中/支払待ち/完了/取消）を手入力
- **返信**（元スレッドへ、差出人=info@固定、確認画面必須）・**新規メール作成**（宛先入力候補=過去の送信先からdatalist補完）
- **「重要」フラグ**: 処理状態とは無関係に、後で見返したいメールを仕分けられる
- **取込除外ルール**（⚙️設定タブ）: 件名/送信元の部分一致・完全一致で、今後の取込自体をブロックできる
- **「対象外にする」**: 請求書ではないと分かったメールを専用タブへ仕分ける（除外ルールとは別物。取込は今後も続く）
- 一覧から複数選択して一括操作（処理開始/支払待ち/完了/対象外/重要）
- ポータルのサイドバーに未処理件数バッジ
- スマホ対応（一覧タップで詳細を全画面表示、ブラウザの「戻る」・トラックパッドのスワイプ戻るにも対応）

## 3. 確定している設計判断（変更するときは必ずユーザー確認）

1. **取込対象はinfo@宛全メール＋「請求書」ラベル**（当初案の「ラベルのみ」から2026-08-24に変更。件名にキーワードが無いメールを取りこぼす実例が出たため）
2. **shunji.nakayama@（社長個人）がToに直接指定されているメールは対象外**（CCに入っているだけの正規スレッドは対象のまま）
3. Gmail側の既読化・アーカイブ操作とは完全に無関係に動く
4. 差出人は返信・新規作成とも`info@ns0314.com`固定。UIに差出人選択欄自体が無い（社長個人アドレスから送信される経路は構造的に無い）
5. 「対象外」（`mail_status='archived'`）と「取込除外ルール」（`invoice_intake_exclusion_rules`）は別物。前者は個別メールをその都度仕分けるだけで今後の取込は止めない
6. 「重要」（`is_important`）は処理ワークフローの状態（`mail_status`）とは独立した別軸のフラグ

## 4. 実機で見つかった不具合と教訓（同種の実装をするときに再発しやすいので記録）

- Gmail検索の`deliveredto:`演算子はこの環境では0件になった（`to:`/`cc:`を使うこと）
- `GmailApp.getAttachments({includeInlineImages:false})`だと、送信元によってはPDFにContent-Disposition:inlineが付き取りこぼす（`true`にして、代わりに100KB未満のimage/*だけ除外する方式に変更）
- Supabase Storageのオブジェクトキーに日本語ファイル名（全角括弧・絵文字含む）をそのまま使うと`Invalid key`で保存が**静かに失敗する**（拡張子だけ引き継いだ連番パスに変更。表示名は別カラムで保持）
- Storageバケットの`allowed_mime_types`を絞りすぎるとzip等が静かにアップロード失敗する（メール添付は種類を絞らず、サイズ上限とRLS・非公開・署名URLだけで守る方針に変更）
- select→insertの2手順は競合でunique制約違反(500)になり得る（`upsert(ON CONFLICT DO NOTHING)`に統一。再実行しても安全に）
- 一覧の読み込みに`limit`を付けたまま総件数がそれを超えると、KPI集計や絞り込みから古いメールが欠落する（KPIはDBへの直接カウント問い合わせに変更、一覧側もlimitを実運用件数より十分大きく設定）
- SPA内の画面遷移（タブ切替・モーダル）を`history.pushState`していないと、ブラウザの「戻る」（トラックパッドのスワイプ含む）でアプリ内ではなくポータルのトップまで戻ってしまう（タブ切替・モーダル表示のたびに履歴を1件積み、単一の`popstate`ハンドラで統一的に処理）

## 6. 運用でよくある操作

- **除外ルールを追加したい**: invoices.html → ⚙️設定タブ → 条件（件名/送信元・部分一致/完全一致）とパターンを入力して追加
- **請求書ではないメールが混ざっている**: 詳細を開いて「🚫 対象外にする」（複数ある場合は一覧でチェック→まとめて対象外）
- **GASの実行状況を見たい**: Apps Scriptエディタ左側の「実行数」アイコン。`runAll`が5分おきに走っているはずで、通常は数秒で完了する（異常に長い・エラーが出る場合は添付の多い大量メールを一度に処理している可能性）
- **手動で今すぐ取り込みたい**: GASエディタで`checkInvoiceMails`（通常運転と同じ・最大50スレッド）または`importAllLabeled`（まとめて・最大200スレッド）を実行
