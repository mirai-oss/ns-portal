# 手順書：Slack 通知の「送り先の部屋」を変えたいとき（2026-11-04）

> いちばん簡単なのは **チャットで伝えるだけ**（→ 1 章）。自分で画面から変えられるものもあります（→ 2 章）。
> どちらでも、Lark／Chatwork 側の今の通知は止まりません（止めるのは別の作業です）。

---

## 0. しくみ（30 秒で分かる版）

- 通知を送るプログラムは、Slack の部屋を **「channel_key」という合言葉**でしか知りません（例：`hq.keiri_kanshi`）。
- 合言葉と Slack の部屋番号（`C0…`）の対応表が 1 つだけあります（ポータル側の `slack_channels`）。
- だから **部屋を変える＝対応表の番号を書き換えるだけ**。プログラムは触りません。
- **Slack で部屋の名前を変えるのは自由**です。番号で追いかけるので、何もしなくて大丈夫。
- **人を入れる・出すのも Slack 側だけ**で完結します。

|---|---|---|
| `keiei.report` | `#経営-レポート` | 鳥一代グループ 8 店の日報・週報・月報（サマリ＋店舗別） |

## 1. いちばん簡単：チャットで伝える（おすすめ）

### 1-1. 既にある通知を、別の部屋に変えたい

1. Slack で新しい部屋を作る（公開でもプライベートでも OK）。
2. その部屋で `/invite @nstyle-notify` を送ってロボットを入れる。
3. 部屋の名前をクリック → 一番下の **チャンネル ID**（`C0…`）をコピー。
4. チャットでこう言う：

```
経理監視の通知を新しい部屋に変えて。ID は C0XXXXXXXXX
```

「経理監視の通知」「経営レポート」「開発システム」など、**上の表の“流れるもの”の言葉で言えば通じます**。合言葉（channel_key）は言わなくて大丈夫です。

→ こちらで対応表の番号を書き換えて、テスト送信 1 通で届くことを確認して報告します。**所要 5 分**。

### 1-2. 1 種類だけ分けたい（例：入金照合だけ別の部屋に）

部屋を作ってロボットを入れ、ID を添えてこう言う：

```
入金照合だけ別の部屋にして。ID は C0XXXXXXXXX
```

→ 新しい合言葉を 1 つ足して、その通知だけ向き先を変えます（プログラムの小さな修正＋デプロイが要るので **所要 30 分〜**。本番デプロイはあなたのターミナルで 1 行実行してもらう場合があります）。

### 1-3. 通知を止めたい／戻したい

```
○○の通知を止めて     ／     ○○の通知を Lark にも戻して
```

→ 設定表の「有効／無効」を切り替えます（消しません。いつでも戻せます）。

### 1-4. 2 つの部屋に同時に送りたい

今の作りは **1 種類の通知＝1 部屋**です。同じ通知を 2 部屋に出したい場合はチャットで言ってください（設定表に行を足して対応します）。

## 2. 自分で画面から変えられるもの

### 2-1. 経営レポート（売上の日報・週報・月報）の「どの店舗をどの部屋に」

nippo（日報サイト）→ 設定 → **店舗管理** → 一番下の **「📮 配信グループ管理」**

- 各店舗カードの「配信グループ所属」のチップを押すと、その店舗をグループに入れたり外したりできます。
- グループの種別が **Slack** のものは、「送り先」欄に合言葉（例 `keiei.report`）が入っています。**ここは変えないでください**（部屋を変えるときは 1 章の方法で）。
- 「有効／無効」のチップで、そのグループへの配信を止められます。
- 最後に **「配信グループを保存する」** を押す。翌日 12:00 の配信から反映されます。

### 2-2. nippo の通知（入社・応募・チーム長の日報など）の有効／無効・テスト

nippo → 設定 → **「🔔 通知の設定」**

- 各通知の **「編集」** → 「この設定を有効にする」のチップで ON/OFF → 保存。
- **「テスト」** ボタンで、その部屋にテスト文を 1 通送れます（届かなければ 3 章へ）。
- 種別が **Slack** の行の「送り先」は合言葉です。ここも変えずに、部屋を変えたいときは 1 章で。

### 2-3. Slack 側でできること（何も連絡いらない）

- 部屋の名前を変える
- 部屋に人を入れる・出す
- 部屋を「プライベート」に変える（ロボットが既に入っていれば OK）

## 3. 届かないとき

| 症状 | まず見るところ |
|---|---|
| 新しい部屋に届かない | ロボットが部屋にいるか（`/invite @nstyle-notify`）。入れたら ID をもう一度教えてください |
| 前は届いていたのに来ない | チャットで「○○の通知、最近届いてる？」と聞いてください。送信台帳（1 通ごとの記録）を見て、送った／失敗した／そもそも発生していない、を答えます |
| 間違った部屋に届く | 1 章の言い方で「○○を △△の部屋に変えて」 |
| 部屋を消してしまった | 新しく作って ID を送ってください。消した部屋への分は失敗として台帳に残るだけで、他の通知には影響しません |
