# 手順書: F/L/FL の分母変更（店内＋デリバリー税抜）— 画面公開前後の数値照合（第2段階の準備・担当A・2026-11-11）

**目的**: 同一店舗・同一期間の F率・L率・FL比率が、DB／API／画面（経営D）で一致することを確認する。公開（app.js・main取り込み）は**まだ行わない**。値は文書に書かない（差・率の判定のみ記録）。
**対象3パターン（当月＝11月月初〜前日、前月＝10月）**: ①鳥一代 本店（デリバリー取扱・売上あり）②芝の鳥一代（デリバリー取扱・売上あり）③鳥一代 恵比寿（デリバリー非取扱＝分母が店内のまま）。
**判定基準**: 率の差 ≤ 0.05pt（0.0005）／sales（店内売上）は完全一致／fl_sales の差 ≤ 1円／非取扱店は fl_sales＝sales で変更前後の率も同じ。
