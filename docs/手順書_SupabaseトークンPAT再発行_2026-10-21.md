# かんたん手順: Supabaseの「アクセストークン」を作って保存する（所要3分）

これをやってもらえると、AI窓口（Hermes）の新しい照会（昨日の店舗別売上など）を私（Claude）が本番に反映できます。
古いトークンは期限切れになっています。**これは私にはできません（あなたのSupabaseアカウントでログインが必要）。**

## やること（5ステップ）

1. パソコンのブラウザで、このページを開く
   **https://supabase.com/dashboard/account/tokens**
   （ログイン画面が出たら、いつものSupabaseのアカウントでログイン）

2. 画面右上あたりの緑のボタン **「Generate new token」** を押す

3. 名前を聞かれるので、**`claude-ns-portal`** と入力して **「Generate token」** を押す

4. **`sbp_` で始まる長い文字列**が1回だけ表示されます。右の **コピー** ボタンでコピーする
   （この画面を閉じると二度と見られません。閉じてしまったら 2 からやり直し）

5. Mac mini の **ターミナル** を開き、下の1行を貼り付けて Enter。`ここに貼る` の部分を、さっきコピーした文字列に置き換えてください

```bash
printf '%s' 'ここに貼る' > ~/.config/ns-portal/supabase_pat && chmod 600 ~/.config/ns-portal/supabase_pat && echo 保存できました
```

「保存できました」と出たら完了です。このチャットで **「保存した」** と教えてください。あとは私が全部やります。

## うまくいかないとき

- 「Generate new token」が見つからない → ページ左の「Access Tokens」を押す
- 貼り付けたら文字化けした → 引用符 `'` が全角になっていないか確認（半角の `'` で囲む）
- `No such file or directory` と出た → 先に `mkdir -p ~/.config/ns-portal` を実行してから、もう一度5を実行

## このトークンでできること・注意

- 私がこのトークンで行うのは、**SQLの適用とEdge Functionのデプロイ**だけです。作業ごとに内容を先に伝えます。
- 作業が終わったら、同じページの **「Revoke」** で無効化してかまいません（次に必要になったらまた発行）。
- トークンはMac miniのこのファイルにだけ置き、リポジトリやチャットには貼りません。
