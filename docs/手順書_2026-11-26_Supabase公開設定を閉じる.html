🔒 Supabase の「鍵かけ」手順書

所要時間：約3分 ／ やること：コピーして貼って、ボタンを1回押すだけ

これは何をするの？

データの倉庫（Supabase）から「鍵をかけ忘れた引き出しがあります」という警告メールが来ました。売掛金や人件費の引き出しが、ログインしなくても見られる状態でした。

今回は、その引き出しに鍵をかけます。ポータルや管理システムは、ログインして使っているので、今まで通り使えます。データは消しません。

1

まず、鍵をかける文章をコピーする

  • 下の青いボタンを1回押します。
✅ できた目印
ボタンが緑色に変わり「コピーしました！」と出ます。
💡 この文章は「SQL（エスキューエル）」といって、データの倉庫に「こうして」とお願いするための、特別な文章です。中身は読まなくて大丈夫です。
中身を見る（見なくてOK）
-- 2026-11-26 Supabase警告(rls_disabled_in_public)対応
-- ログイン不要で読めていた14件を閉じる。ログイン済みのポータル/管理システム・サービスキーで動く取込は今まで通り動く。
-- 残す（意図的に公開: 申請フォーム・GAS・日報が公開キーで読む）: store_directory_v / cost_transfer_items_v / google_review_log_v / kd_sync_status_v / report_channel_matrix_v
-- テーブル: RLSを有効化＋ログイン済みユーザーには従来どおり全操作を許可するポリシーを追加（既にポリシーがあれば追加しない）＋anonの権限を外す
-- ビュー: anonの権限を外す
do $$
declare n text; k "char";
begin
  foreach n in array array[
    'ai_users_v','api_cost_daily','ar_deposits','ar_receivable_attachments','ar_receivables','ar_recurring_master',
    'cash_handoff_role_scope','google_review_legacy_compare_v','google_review_store_daily_v','import_status_today',
    'labor_allocation_compare_report','labor_salary_daily_weight','labor_salary_pay_type','sync_status_v']
  loop
    select c.relkind into k from pg_class c join pg_namespace s on s.oid=c.relnamespace
      where s.nspname='public' and c.relname=n;
    if k is null then continue; end if;
    if k in ('r','p') then
      execute format('alter table public.%I enable row level security', n);
      if not exists (select 1 from pg_policies where schemaname='public' and tablename=n) then
        execute format('create policy authenticated_full_access on public.%I for all to authenticated using (true) with check (true)', n);
      end if;
    end if;
    execute format('revoke all on public.%I from anon', n);
  end loop;
end $$;

-- 結果確認: 「まだRLSが無効のテーブル」と、anonが読めるかを一覧表示（残りの調査用）
select c.relname as table_name,
       has_table_privilege('anon', c.oid, 'select') as anon_can_read,
       has_table_privilege('anon', c.oid, 'insert,update,delete') as anon_can_write
from pg_class c join pg_namespace s on s.oid=c.relnamespace
where s.nspname='public' and c.relkind in ('r','p') and not c.relrowsecurity
order by anon_can_write desc, anon_can_read desc, 1;
2

Supabase を開く

  • ここをクリック（新しいタブで開きます）。
  • ログインを求められたら、いつものメールとパスワードでログインします。
✅ できた目印
「Your projects」（プロジェクト一覧）のような画面が出ます。
3

「ニッポ」を開く

  • 一覧の中から、「ニッポ」という名前のカードを探します。
  • そのカードをクリックします。
✅ できた目印
左上に「ニッポ」と出て、左側に縦のメニューが並びます。
4

「SQL Editor」を開く

  • 左側の縦のメニューから、「SQL Editor」（</> のような記号）をクリックします。
  • 見つからないときは、メニューを下へスクロールします。
  • 左上の「＋ New query」をクリックします。
✅ できた目印
中身が空っぽの、文字を入れる大きな四角が開きます。
5

貼り付ける

  • 大きな四角の中を、1回クリックします。
  • キーボードで ⌘（コマンド）を押しながら V を押します。
✅ できた目印
do $$ で始まる英語の文章がたくさん入ります。一番下に select c.relname as table_name, の行があれば、全部貼れています。
⚠️ うまくいかないとき
何も出ない・別の文章が出たときは、ステップ1に戻って、もう一度コピーボタンを押してください。
6

「Run」を押す

  • 右下の緑色のボタン「Run」をクリックします。
  • 「この文章を実行しますか？」と確認が出たら、「Run this query」をクリックします。
💡 「データを消す操作が含まれています」のような注意が出ても大丈夫です。今回は鍵をかけるだけで、データは消しません。
✅ できた目印
四角の下に表が出ます。一番上の行に table_name・anon_can_read・anon_can_write と書いてあります。
⚠️ うまくいかないとき
赤い文字が出たら、何も押さずに、その画面をスクリーンショットして私に送ってください。
7

結果を私に見せる

  • 下に出た表を、画面ごとスクリーンショットします（⌘＋Shift＋4 で範囲を選べます）。
  • その画像を、私に送ってください。
✅ できた目印
私が「鍵がかかったか」を確かめて、結果を返します。これで完了です。

もし、ポータルや管理システムの調子が悪くなったら

ほぼ起きませんが、「前は見えていた数字が出ない」ときは、慌てずに私に「元に戻して」と言ってください。すぐ元の状態に戻せます。

自分で戻したいとき

ステップ4〜6と同じ手順で、下の文章を貼って Run します。

-- 2026-11-26_close_anon_exposure.sql を元に戻す（何か動かなくなったときだけ使う）
do $$
declare n text; k "char";
begin
  foreach n in array array[
    'ai_users_v','api_cost_daily','ar_deposits','ar_receivable_attachments','ar_receivables','ar_recurring_master',
    'cash_handoff_role_scope','google_review_legacy_compare_v','google_review_store_daily_v','import_status_today',
    'labor_allocation_compare_report','labor_salary_daily_weight','labor_salary_pay_type','sync_status_v']
  loop
    select c.relkind into k from pg_class c join pg_namespace s on s.oid=c.relnamespace where s.nspname='public' and c.relname=n;
    if k is null then continue; end if;
    execute format('grant select on public.%I to anon', n);
    if k in ('r','p') then
      execute format('drop policy if exists authenticated_full_access on public.%I', n);
      execute format('alter table public.%I disable row level security', n);
    end if;
  end loop;
end $$;
🚫 やってはいけないこと
メールの中の「問題を解決する」ボタンは押さないでください。画面の動きを確かめずに全部へ鍵をかけるボタンなので、日報や人件費が動かなくなる恐れがあります。
