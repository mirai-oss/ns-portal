## ④ 自動heartbeat（H-5・PC1台につき1回）

Claude Codeが動くだけでLIVEカードが自動更新されるようにするフック設定。各Macのターミナルで下を実行（何度実行しても安全・既存設定は保持）:

```bash
python3 - <<'EOF'
import json, os
p = os.path.expanduser("~/.claude/settings.json")
try: s = json.load(open(p))
except Exception: s = {}
CMD = '[ -x "$HOME/ns-portal/tools/ai-cockpit" ] && "$HOME/ns-portal/tools/ai-cockpit" %s >/dev/null 2>&1 || true'
h = s.setdefault("hooks", {})
def add(event, matcher, action):
    lst = h.setdefault(event, [])
    if any("ai-cockpit" in hk.get("command","") for e in lst for hk in e.get("hooks",[])):
        print(event + ": 設定済み"); return
    e = {"hooks":[{"type":"command","command":CMD % action,"timeout":15,"async":True}]}
    if matcher: e["matcher"] = matcher
    lst.append(e); print(event + ": 追加")
add("SessionStart", None, "hb")
add("PostToolUse", "Edit|Write|Bash|NotebookEdit", "hb")
add("Stop", None, "idle")
json.dump(s, open(p,"w"), ensure_ascii=False, indent=2)
print("OK:", p, "（次に起動するClaude Codeセッションから有効）")
EOF
```

- 仕組み: セッション開始・ファイル編集/コマンド実行のたび→`ai-cockpit hb`（20秒間引き）／応答完了→`idle`。担当名を名乗らないセッションはリポジトリ名で表示される
- 事前条件: そのPCに `~/ns-portal`（git pull済み）と `~/.ns-cockpit/config`（②）があること

## トークンを変えたくなったら

新しい値で①-3のSQLを再実行 → 各PCの `~/.ns-cockpit/config` のTOKEN行を書き換え。
